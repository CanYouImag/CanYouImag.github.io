# 第一章 导论

## 马克思主义的组成部分

- 马克思主义哲学——马克思主义的基础和方法论
- 马克思主义政治经济学——主体内容
- 科学社会主义——马克思主义的目的和归宿

## 马克思主义的基本立场、基本观点和基本方法

**马克思主义的基本立场**：以人民为中心，坚持一切为了人民，一切依靠人民，全心全意为人民服务。（选择题问你马克思主义基本立场，就选选项中带无产阶级，带人民的）

**马克思主义基本观点**：是关于自然、社会和人类思维发展一般规律的科学认识。（涉及的观点很全面，所以命题老师编题的时候会以偏概全，如“马克思主义只是关于人类社会的学说”就是错的）

**马克思主义基本方法**：辩证唯物主义（第二章），历史唯物主义（第四章）

## 马克思主义的创立

早期组织“正义者同盟”（不是政党，是因为此时“正义者同盟”还没有自己的党章）邀请马克思、恩格斯指导，然后马克思和恩格斯将“正义者同盟”改组成“共产主义者同盟”，并起草《共产党宣言》。《共产党宣言》是历史上第一个无产阶级政党的党纲，也是马克思主义公开问世的标志。

- 马克思主义的产生有深刻的社会根源、阶级基础和思想渊源
  - 社会根源：资本主义生产方式在西欧已经有了相当的发展（也是马克思主义的时代背景）
  - 阶级基础：无产阶级反抗资产阶级剥削压迫的斗争中（也是马克思主义的实践基础）。
  - 补充知识点：法国、英国、德国工人运动的兴起（早期欧洲的三大工人运动），标志着现代无产阶级作为独立的政治力量登上了历史舞台。而中国的无产阶级登上历史舞台的标志是$1919$五四运动，不要混淆。
  - 思想渊源：德国古典哲学（马克思主义哲学的理论来源）、英国古典政治经济学（马克思主义政治经济学的理论来源）、英法空想社会主义（科学社会主义的理论来源）。

## 马克思主义的发展

列宁认为经济政治发展的不平衡已成为资本主义发展的绝对规律，并提出社会主义革命可能在一国或者多国率先取得胜利的论断。（就是说世界上的资本主义国家的发展水平不是绝对相当的，有些资本主义国家还处于萌芽阶段，有的资本主义国家已经进入了高度发达的帝国主义垄断阶段，所以资本主义不会同时灭亡，而是有的资本主义先发展，先灭亡，先进入社会主义和共产主义，因此社会主义革命可能在一国或者多国率先取得胜利）

## 马克思主义的基本特征

（深刻理解每个特点的含义）

- 科学性：马克思主义是对自然，社会和人类思维发展本质和规律的正确反映（是马克思主义的基本特征，鲜明特征，也是马克思主义独有的特征）
- 人民性：是马克思主义的本质属性，是马克思主义的政治立场
- 实践性：实践观点是马克思主义首要和基本的观点（也是马克思主义独有的观点）
- 发展性：马克思主义是不断发展的开放的学说，具有与时俱进的品质

马克思主义的基本特征就是科学性与革命性的统一，革命性是马克思主义的内在品质，是马克思主义的人民性、实践性、发展性的应有之义和必然要求（人民性+实践性+发展性=革命性）

# 第二章 世界的物质性及发展规律

## 总纲

马克思主义哲学整体上分为四大部分：

| 组成部分 | 回答 / 研究的问题 |
| --- | --- |
| **唯物论** | "世界是什么" |
| **辩证法** | "物质世界是怎样存在的" |
| **认识论** | "我们将如何认识这个世界" |
| **唯物史观** | 人类社会 / 人类历史的发展规律 |


## 唯物论

### 一、哲学的基本问题和不同哲学流派

> **哲学的基本问题**：恩格斯说："全部哲学，特别是近代哲学的重大的基本问题，是思维（精神、意识）和存在（物质）的关系问题"。

> **关联**：这一基本问题在社会历史领域的延伸，即"社会存在与社会意识的关系问题"，是**社会历史观的基本问题**（见「唯物史观」）。

哲学的基本问题可以展开为以下两个方面：

#### （一）方面一：物质和意识何者为第一性（即先有谁后有谁的问题）

**$1$. 唯物主义**——认为先有物质后有意识，其内部分歧在于：什么是物质？

| 流派 | 对"什么是物质"的回答 |
| --- | --- |
| **古典唯物主义（朴素唯物主义）** | 物质是一种或几种实物 |
| **机械唯物主义（形而上学唯物主义）** | 物质是构成物质的最小粒子 |
| **旧唯物主义（半截子唯物主义）** | 包含前两类——观察自然界的时候持唯物主义观点，但在研究人类历史的时候采用唯心主义观点 |
| **辩证唯物主义（马克思的唯物主义）** | 物质是一切客观存在，包含了前两派 |

> **补充$1$（包含关系）**：前两派认为是物质的，辩证唯物主义一定认为是物质；但辩证唯物主义认为是物质的，前两派不一定认为是物质（如：人类历史）。所以辩证唯物主义可以说是哲学史上第一个把人类历史当作物质去研究的，这就是"唯物史观"。
>
> **补充$2$（历史贡献 ①）**：马克思在哲学史上的两大历史贡献之一：**① 创立了唯物史观**。

**$2$. 唯心主义**——认为先有意识后有物质，其内部分歧在于：什么是精神？

| 流派 | 观点 | 例证 |
| --- | --- | --- |
| **主观唯心主义** | 本我的精神，我心就是世界的本原 | 笛卡尔的"我思故我在"；禅宗慧能的"菩提本无树，明镜亦非台，本来无一物，何处惹尘埃？" |
| **客观唯心主义** | 独立于人之外的精神，即"我之上"的精神 | 中国道家的"道生一，一生二，二生三，三生万物" |

#### （二）方面二：物质和意识是否具有同一性

（我们人类的意识能不能认识外部世界的物质；能认识就是有同一性，不能认识就是没有同一性）

| 立场 | 观点 |
| --- | --- |
| **可知论** | 有同一性，即世界是可以被认识的（唯物主义和唯心主义统统都是可知论） |
| **不可知论** | 没有同一性（二元论者，认为物质和意识都是世界的本原，即眼前的物质不是脑中的意识的反映、意识不是物质的投射，导致眼前的物质在一个世界，脑中的意识在另一个世界） |

#### （三）哲学的重要问题：世界是怎样存在的

（回答完基本问题之后进一步回答的问题）

| 立场 | 观点 |
| --- | --- |
| **形而上学** | 世界是孤立的、片面的、静止的、无矛盾的 |
| **辩证法** | 世界是联系的、全面的、发展的、矛盾的 |

#### （四）流派的两两组合与马克思的历史贡献

- 例如：一个认为物质是世界本源的哲学家，如果认为世界是孤立的、片面的、静止的，那他就是**形而上学的唯物主义**。
- 辩证法、形而上学和唯物主义、唯心主义两两结合，理论上可以有四种不同的结果；但是在马克思之前，哲学界是没有辩证唯物主义的，只有其他三种。
- 这就又回到了前面那个马克思在哲学史上的**第二个历史贡献**：**② 首次将辩证法引入唯物论，形成了辩证唯物主义**。

### 二、物质范畴及其理论意义

**恩格斯对物质的定义**：物、物质无非是各种物的总和，而这个概念就是从这一总和中抽象出来的（抽象：指的是在这所有的物中提炼出共同的性质。所有物质的共性是：客观实在）。

请注意「物质」与「物质的概念」并不等价：

$$
\left\{
\begin{aligned}
&\text{物质：世界上所有物的总和} \\\\
&\text{物质的概念（物质的范畴）：从物的总和中抽象出来的共性}
\end{aligned}
\right.
$$

> 所以表述"物质的概念无非就是各种物的总和"是**错**的，因为"物质"才是总和，"物质的概念"不是。

**列宁对物质的定义**：物质是标志客观实在的哲学范畴，这种客观实在是人通过感觉感知的（可知论），它不依赖于我们的感觉而存在（客观实在）。（说明了物质是不依赖于人类的意识而存在，并能为人类的意识所反映的客观实在。这种客观实在性，是从自然存在和社会存在中抽象出来的共同属性）

### 三、物质和运动

**运动的概念**：运动是标志一切事物和现象的变化及其过程的哲学范畴，**（在考研政治中，运动等同于变化，所有能用到运动上的表述也能用到变化上）**，运动是物质的*存在方式*和*根本属性*。

**物质和运动的关系**：不可分割——运动是物质的运动，物质是运动的物质。

> - 只看物质不看运动的人是**形而上学**，只看运动不看物质的是**唯心主义**。马克思看问题总是看两边，错误的观点就是夸大一边、忽略另一边，走向一个极端。
> - （两个概念的不可分割关系：两个概念的词性不一样，公式：你是我的你，我是你的我。）

### 四、运动和静止

**静止的概念**：相对静止是物质运动在一定条件下的稳定状态，具体包括空间的相对位置暂时不变和事物的根本属性暂时不变这样两种运动的特殊状态。

**运动和静止的关系**：对立统一（两个概念的对立统一关系：两个概念的词性一样，因为既有对立的一面又有统一的一面，公式：两者之间既相互区别，又相互联系）。

- **相互区别**：运动的绝对性体现了物质运动的变动性、无条件性；静止的相对性体现了物质运动的确定性、有条件性。
- **相互联系**：运动和静止相互依赖、相互渗透、相互包含，"动中有静，静中有动"。

> - 只看运动不看静止是**诡辩论**，只看静止而不看运动是**形而上学**。
> - **诡辩论**：过分的夸大事物的变动，连暂时的静止都不承认。例如：你昨天找我借了$50$块钱，今天我要你还钱的时候你说"你找我没用，找你借钱的是昨天的我，不是今天的我"。

### 五、物质运动与时空

**时空的概念**：

- **时间**：是指物质运动的持续性、顺序性，特点是一维性（时间一去不复返）。
- **空间**：是物质运动的广延性、伸张性，特点是三维性（长宽高）。

**物质运动和时空的关系**：不可分割（时空是物质运动的时空，物质运动是时空的物质运动），时间和空间是运动着的物质的基本存在形式。

**时空的特点**：

| 特点 | 含义 |
| --- | --- |
| **客观性** | 不以人的意志为转移 |
| **有限性** | 从具体事物的角度来说，时空是有限的 |
| **无限性** | 整个物质世界的时空是无限的 |
| **绝对性** | 时空是绝对存在的，即我们所有人认识到的时空是一样的 |
| **相对性** | 突破一定速度极限时，时空就没那么绝对了（相对论） |

### 六、物质世界的二重化

人类的出现，特别是人类改造世界的实践活动，极大地改变了世界的面貌，使世界发生了二重分化：从自然界分化出人类社会，从客观世界分化出主观世界（在人类出现之前，物质世界和自然界是等同的）。

- **一方面**，世界分化为**自然界**和**人类社会**，人类社会是最高级的物质存在形态。自然界和人类社会不是截然分开的，而是交叉重叠的。
- **另一方面**，世界划分为**客观世界**和**主观世界**，主观世界从客观世界分化出来（这句话坚持了唯物主义），具有相对独立性。

> **相对独立性**：一个学生和一个老师之间有教学的关系。老师教学生东西，所以学生不具备绝对独立性，但是学生具备相对独立性，即老师教的东西学生会认同一部分，而不是全盘接受，因为如果不具备相对独立性的话，学生就会变得老师教什么学生知道什么，老师说什么学生认同什么，除此之外的东西学生根本不知道。（人会有回忆也是因为意识世界的相对独立性）

但是主观世界并非一个独立存在的实体，也不是一个超然于客观世界而孤立存在的世界（这句话批判了二元论），它不能完全脱离于客观世界，而是从属于客观世界。

> **关键**：人的实践活动是自然界和人类社会、客观世界与主观世界分化的关键，也是**它们统一的关键**。

### 七、物质与意识的辩证关系

#### （一）意识的起源

意识既是**自然界长期发展的产物**，也是**社会历史发展的产物**：

- **自然界**：由一切物质所具有的反应特性 → 低等生物的刺激感应性 → 高等动物的感觉和心理 → 最终发展为人类的意识。（意识是人独有的）
- **社会历史**：社会实践，特别是**劳动**，在意识的产生和发展中起着**决定性作用**；在人们的劳动和交往中形成的**语言**促进了意识的发展（**促进作用 / 重要影响**）。

> **易错点**：考试的时候会把"重要影响"的因素拔高为"决定性因素"，例如"语言在意识的产生过程中起到决定性作用"，这个论述是**错的**；也会把"重要影响"的因素贬低为没有影响，例如"在意识产生的过程中，语言是无关紧要的、可有可无的"，这也是**错的**。

#### （二）意识的本质

1. 意识是人脑这样一种特殊物质的机能和属性（不等于大脑本身，即"意识就是人脑"或"意识是人脑的分泌物"这两个观点就是错误的，因为它混淆了物质和意识的分界线）。
2. 意识是客观世界的主观映像（是一个能动反映，即会对外部世界的映像进行创造性的加工和改造）。意识在内容上是客观的，在形式上是主观的。

> 马克思指出："观念的东西不外是**移入人脑**（反映）并在人的头脑内**改造过的**（能动）物质的东西而已。"

**两种错误观点**：

- 只看能动、不看反映 → **唯心主义 / 不可知论**
- 只看反映、不看能动 → **旧唯物主义（直观反映论 / 机械反映论）**

#### （三）意识对物质的反作用（意识的能动作用）

- 意识具有目的性和计划性
- 意识具有创造性
- 意识具有指导实践、改造客观世界的作用
- 意识具有调控人的行为和生理活动的作用

#### （四）物质和意识的辩证关系（对立统一关系）

| 相互区别 | 相互联系 |
| --- | --- |
| ① 物质是本源，意识是派生 | ① 物质可以转化为（变成）意识，意识可以转化为（变成）物质 |
| ② 物质不是意识，意识不是物质 | ② 意识对物质既有依赖性，又有相对独立性 |
| ③ 物质不能代表意识，意识不能代表物质 | ③ 物质决定意识，意识反作用于物质 |

> **关联**：意识对物质的"依赖性""相对独立性"以及它的能动反作用，在社会历史领域表现为**社会意识的相对独立性**及其**对社会存在的反作用**（见「唯物史观」）。

### 八、主观能动性和客观规律性的统一

一方面，尊重客观规律是正确发挥主观能动的前提。

另一方面，只有充分发挥主观能动性，才能正确认识和利用客观规律。

**实践**是客观规律与主观能动性统一的基础。

**发挥主观能动性的前提和条件**：

1. 从实际出发是正确发挥人的主观能动性的前提
2. 实践是正确发挥人的主观能动性的根本途径
3. 正确发挥人的主观能动性，还要依赖于一定的物质条件和物质手段

> 成功的实践既要遵循规律，又要发挥能动。如果题干中的故事明显体现其中一个重要，那么选项就要选和他相关的。

> **关联**：这一原理在社会历史领域的运用，即社会形态更替中的"**必然性和选择性**"（必然性即规律性、选择性即能动性，见「唯物史观」）。

### 九、意识与人工智能

**人工智能的实质**：实质上是对人脑组织结构与思维运行机制的模仿，是人类智能的物化。（物化：指把虚无缥缈的东西以物的形式表达出来）

**人工智能对人类的影响**：尽管人工智能可以模拟和扩展人脑的某些活动，甚至在计算速度和准确度、程序化任务的执行能力等方面的表现超出人类所能，但即使是计算能力再强，也达不到人类智能的层级，无法真正具有人的意识，不可能取代或超越人类智能。

> **考点**：① 论断"人工智能在任何方面都不能超越人类智能"是**错误**的；② 论断"人工智能可以全面超越 / 取代人类"也是**错误**的。

**人工智能不可能取代或超越人类智能的原因**：

1. 人类意识是知情意的统一体，而人工智能只是对人类的理性智能的模拟和扩展，不具备情感、信念、意志等人类意识形式（感性内容）。
2. 社会性是人的意识固有的本质属性，而人工智能不可能具有人的社会属性。
3. 人类的自然语言是思维的物质外壳和意识的现实形式，而人工智能难以完全具备理解自然语言意义的能力。
4. 人工智能能够获得人类意识中可以化约成数字信号的内容，但人脑中总有许多东西是无法被化约的。

### 十、世界的物质统一性原理（总结唯物论）

1. 自然界是物质的。
2. 人类社会本质上是生产实践基础上形成的物质体系。
3. 人的意识统一于物质。

> **方法论**（这个原理教会了我们什么道理）：世界的物质统一性原理是辩证唯物主义最基本、最核心的观点，是马克思主义的基石。一切从实际出发，就是这个原理在现实生活中和实际工作中的生动体现。


## 唯物辩证法

> **辨析**：本部分的"唯物辩证法第一 / 第二 / 第三规律"（对立统一、量变质变、否定之否定），指的是**物质世界（自然界、社会和思维）运动发展的一般规律**；不要与「唯物史观」中"人类社会发展的第一 / 第二规律"（生产关系一定要适合生产力状况、上层建筑一定要适合经济基础状况）混淆。

### 一、唯物辩证法的两大总特征

#### （一）事物的普遍联系

联系的特点：

- **客观性**——不以人的意志为转移
- **普遍性**：
  - 任何事物内部的不同部分和要素之间都是相互联系的（事物内部有联系）
  - 任何事物都不能孤立存在，都与其他的事物处在一定的联系之中（事物之间有联系）
  - 整个世界是相互联系的统一整体，每一个事物都是世界普遍联系中的一个成分或环节；世界的普遍联系是通过"中介"来实现的（世界上任何事物都通过中介联系其他事物，同时也是其他事物联系的中介）
- **多样性**
- **条件性**：
  - 条件对事物发展和人的活动具有支持或制约作用
  - 条件是可以改变的，人们经过努力可以化不利条件为有利条件，推动事物的发展
  - 改变和创造条件不是任意的，必须尊重事物的发展规律

> **方法论意义**：用系统的观点去看待世界的发展（事物的联系教会了我们什么）。

#### （二）事物的变化发展

**发展的内涵（概念）**：一切形式的变化就是运动，发展则是事物变化中前进的、上升的运动。（考研政治中，运动$=$变化，但是不等于发展。因为运动和变化都有前进的、顺应规律的，也有后退的、倒行逆施的；发展指的就是前进的、顺应规律的运动。所以说，运动$=$变化$\gt$发展。因此可以说事物是无条件的、无时无刻不处于运动和变化之中，但不能说它每时每刻都在发展，而可以说发展是永恒的。）

**发展的实质**：新事物的产生和旧事物的灭亡。（新事物指合乎历史前进方向、具有远大前途的东西；旧事物指丧失历史必然性、日趋灭亡的东西。新旧事物的区别与时间顺序无关。）

**新事物必然战胜旧事物的原因**：

1. 就新旧事物与环境的关系而言，新事物有新的要素、结构和功能，它适应了已经变化了的环境和条件。
2. 就新事物和旧事物的关系而言，新事物是在旧事物的"母体"中孕育成熟的，它既否定了旧事物中消极腐朽的东西，又保留了旧事物中合理的、适应新条件的因素，并增加了旧事物所不能容纳的新内容。
3. 在社会历史领域，新事物从根本上符合人民群众的利益和要求，能够得到人民群众的拥护，因而必然战胜旧事物。

> **方法论意义**：看待任何事物要以过程的观点去看（过程的观点：指万事万物都是一个过程）。

### 二、对立统一规律——唯物辩证法第一规律

对立统一规律是唯物辩证法的实质和核心，因为它揭示了事物普遍联系的根本内容和变化发展的内在动力，从根本上回答了事物为什么会发展的问题。

#### （一）矛盾的同一性和斗争性及其辩证关系（关系原理）

**矛盾**：指哲学中世间万事万物皆以一对、一对的形式出现，就是矛盾。

对立和统一分别体现了矛盾的两种**基本属性**。矛盾的对立属性又叫**斗争性**，矛盾的统一属性又叫**同一性**（同一和统一可以相互换用，但"同一"搭配"斗争"，"统一"搭配"对立"）。

**矛盾的同一性**：指矛盾的对立面相互依存、相互贯通的性质和趋势：

1. 矛盾着的对立面相互依存，互为存在的前提。
2. 矛盾着的对立面相互贯通，在一定条件下可以相互转化。

**矛盾的斗争性**：指矛盾着的对立面相互排斥、相互分离的性质和趋势（同一和斗争，不是时而……时而……的关系，而是既……又……的关系）。由于矛盾的性质不同，矛盾的斗争形式不同，可分为：

- **对抗性矛盾**（比较激烈）
- **非对抗性矛盾**（比较缓和）

**同一性和斗争性的关系**：同一性不能脱离斗争性而存在，没有斗争性就没有同一性，没有同一性就没有斗争性；斗争性寓于同一性之中，同一性通过斗争性体现。在事物的矛盾之中，斗争性是无条件的、绝对的；同一性是有条件的、相对的（斗争指的是事物之间的区别，同一指的是事物之间的联系）。

> **方法论意义**：矛盾的同一性和斗争性同时存在，因此事物总是具有两面性，这要求我们在看待事物的时候要做到"一分为二"。

#### （二）同一性和斗争性在事物发展中的作用（作用原理）

**同一性在事物发展中的作用**：

1. 由于矛盾双方相互依存，互为存在的条件，矛盾双方可以利用对方的发展使自己得到发展。
2. 由于矛盾双方相互包含，矛盾双方可以相互吸收有利于自身的因素得到发展。
3. 由于矛盾双方彼此相通，矛盾双方可以向着彼此的对立面转化而得到发展。

**斗争性在事物发展中的作用**：

1. 矛盾双方的斗争促进矛盾双方力量的对比发生变化，此消彼长，造成事物的**量变**。
2. 矛盾双方的斗争促使矛盾双方的地位或性质发生转化，实现事物的**质变**。

> **方法论意义**：说明事物的发展不仅表现出"**相辅相成**（矛盾的同一性）"，也能表现出"**相反相成**（矛盾的斗争性）"。这就要求我们学会逆向思维，当一个问题的思考不明白的时候不妨反过来想它。

#### （三）矛盾的普遍性和特殊性及其辩证关系（关系原理）

**矛盾的普遍性**：矛盾无处不在，矛盾无时不有。

**矛盾的特殊性**：各个具体事物的矛盾、每个矛盾的各个方面在发展的不同阶段上各有其特点：

1. 不同事物的矛盾各有其特点。
2. 同一事物的矛盾在不同发展过程和发展阶段各有不同特点。
3. 构成事物的诸多矛盾以及每一矛盾的不同方面各有不同的性质、地位和作用。

**矛盾的普遍性和特殊性是辩证统一的关系**：矛盾的普遍性即矛盾的共性，矛盾的特殊性即矛盾的个性（普遍性 / 特殊性可以替换成共性 / 个性）。矛盾的共性是无条件的、绝对的；矛盾的个性是有条件的、相对的。任何现实存在的事物都是共性和个性的有机统一，共性**寓于**个性之中，没有离开个性的共性，也没有离开共性的个性。

> **方法论意义**：矛盾的共性和个性的道理是矛盾问题的**精髓**。人的认识的一般规律是由认识个别上升到认识一般，再由认识一般到认识个别的辩证发展过程。矛盾的普遍性和特殊性的关系原理，还是马克思主义基本原理同各国实际相结合的哲学基础（即马克思主义（共性）中国化（个性）的哲学基础）。

#### （四）矛盾的不平衡发展原理

**主要矛盾**是矛盾体系中处于支配地位、对事物发展起决定性作用的矛盾；**次要矛盾**在矛盾体系中处于从属地位、对事物发展起次要作用的矛盾。

在每一对矛盾中，又有矛盾的主要方面和矛盾的次要方面。**事物的性质是由主要矛盾的主要方面所决定的。**

> **方法论意义**：在处理问题时，既要看到主要矛盾、强调主要矛盾，又要看到次要矛盾、不忽略次要矛盾，要坚持"两点论"和"重点论"的统一。

### 三、量变质变规律——唯物辩证法第二规律

#### （一）基础概念

- **质：**是一事物区别于其他事物的内在规定性。认识质是认识事物的起点和基础。**只有认识质，才能区别事物**。（就是事物是什么的问题）
- **量：**是事物的规模、程度、速度等可以用数量关系表示的规定性。**认识事物的量是认识的深化和精确化**。**只有正确了解事物的量，才能正确估计事物在实践中的地位和作用**。
- **度：**事物的量和质是统一的，它们的统一在度中得到体现。度是保持事物质的稳定性的数量界限，即事物的限度、幅度和范围。度的两端叫**关节点**或**临界点**，超出度的范围，事物就会变成别的事物。（启示：在认识和处理问题时要掌握**适度原则**）
- **量变：**是事物数量的增减和组成要素排列次序的变动，是保持事物的相对稳定性的**不显著变化**，体现了事物发展渐进过程的**连续性**（因为量变是一个连续变化的过程）。
- **质变：**是事物性质的根本变化。是事物由一种质态向另一种质态的飞跃，体现了事物发展渐进过程和连续性的**中断**（因为质变是积累到一个瞬间突然变化）。

#### （二）量变和质变的辩证关系

量变和质变的关系是对立统一关系，既相互区别，又相互联系。具体来说：

- 量变是质变的**必要准备**。
- 质变是量变的**必然结果**。

也就是说，想要达到质变必须经过量变的准备，当量变积累到一定程度之后，必然会迎来质变的结果。

量变和质变是相互渗透的：在总的量变过程中有阶段性的和局部性的部分质变；在质变过程中也有旧的质在量上的收缩和新的质在量上的扩张。

**两种错误观点**：

- 只看质变不看量变 —— **激变论**
- 只看量变不看质变 —— **庸俗进化论**

#### （三）方法论意义

当事物的发展处于量变阶段时，要踏踏实实做好日常工作，为未来重大改变做准备；当质变来临的时候，要果断地、不失时机地抓住机遇，促成质变，使工作迈上新台阶。

### 四、否定之否定规律——唯物辩证法第三规律

#### （一）肯定因素和否定因素

- **肯定因素：**是维持现存事物存在的因素。
- **否定因素：**是促使现存事物灭亡的因素。

（任何事物体内既有肯定因素，又有否定因素，只是肯定因素和否定因素的量的多少的问题。）

#### （二）辩证否定观

- **自我否定**：否定是事物的自我否定——辩证法认为事物按照自身规律运动发展，自己否定自己；形而上学则认为否定是外在力量消灭事物。
- **发展的环节**：否定是事物发展的环节。
- **联系的环节**：否定是新旧事物联系的环节。
- **实质是"扬弃"**：辩证否定的实质是"扬弃"，即既克服又保留；形而上学主张"要么肯定一切，要么否定一切"。

#### （三）否定之否定规律

**否定之否定规律：**（解释事物发展的方向）事物的辩证发展过程经过第一次否定，使矛盾得到初步解决，而处于否定阶段的事物仍然具有片面性，还要经过再次否定，即否定之否定，实现对立面的统一，使矛盾得到根本解决。事物的辩证发展就是经过两次否定，三个阶段，即"肯定——否定——否定之否定"，形成一个周期。其中，否定之否定阶段**仿佛是**给原来出发点的回复，但这个回复是在更高阶段的回复，是"扬弃"的结果。事物的发展呈现周期性，不同周期交替使事物的发展呈现波浪式前进或螺旋式上升的总趋势。

> 口语化理解：否定之否定阶段得到的东西，变成了一个"更厉害"的原事物。

**两种错误观点**：

- 只看螺旋不看上升 —— **循环论**（例如某些宗教主张的轮回）
- 只看上升不看螺旋 —— **直线论**

#### （四）方法论意义

由于事物发展是前进性和曲折性的统一，我们就不能奢望什么事情都是一帆风顺的。要善于洞察事物发展中的各个可能性，充分估计其困难和曲折，经得起困难和挫折的考验。

> **关联**：否定之否定规律所揭示的"波浪式前进、螺旋式上升"，在社会历史领域表现为社会形态更替的**前进性和曲折性**（见「唯物史观」）。

### 五、辩证法的五大基本范畴

#### （一）内容和形式——第一对基本范畴

- **内容的概念：**内容是指构成事物的一切要素的总和，是事物存在的基础。
- **形式的概念：**把诸要素统一起来的结构或表现内容的方式。
- **内容和形式的关系：**
  - 相互依存，相辅相成。任何事物的内容都有一定形式，任何形式也都有一定内容；没有无内容的呈现形式，没有无形式的纯粹的内容。
  - 内容决定形式，形式反作用于内容。当形式适合内容时，对内容的发展起着积极的推动作用，当形式不适合内容时，对内容的发展起着消极的阻碍作用。
- **方法论意义：**既要重视内容，又要善于运用形式，发挥其积极作用。

#### （二）现象和本质——第二对基本范畴

- **现象的概念：**是事物的外部联系和表面特征，是事物本质的外在表现，人们可以**通过感官感知**。
- **本质的概念：**本质是事物的根本属性，是构成事物的诸要素之间的内在联系，只有**通过理性思维才能把握**。
- **现象和本质的关系：**现象和本质既相互区别，又相互联系。
  - **相互区别**：现象是个别的、具体的，而本质是一般的、普遍的；现象是多变易逝的，本质是相对稳定的；现象是生动丰富的，本质是深刻单纯的。现象有真象和假象之分，假象和错觉不是一回事。（假象：是一种歪曲表达本质的现象，是客观存在的；错觉：是一种感觉，属于一种主观上错误的认知）
  - **相互联系**：任何本质都通过现象表现出来，没有不表现为现象的本质，任何现象都从一定的方面表现着本质，现象是本质的外部表现，即使是假象也是本质的表现。
- **方法论意义：**通过现象看本质是科学研究的任务。

#### （三）原因和结果——第三对基本范畴

- **原因的概念：**引起某种现象的现象就是原因。
- **结果的概念：**被某种现象引起的现象叫结果。
- **原因和结果的关系（辩证关系）：**
  - 原因和结果的关系既是确定的，又是不确定的。（在同一个事情当中，原因就是原因，结果就是结果。但在多个事物中，一个结果有可能是另一个现象的原因，所以是不确定的）
  - 原因和结果相互作用，原因产生结果，结果反过来影响原因。
  - 原因和结果相互渗透，结果存在于原因之中，原因表现在结果之中。（看到因就能猜测果，看到果就能推测因）
  - 原因和结果的关系是**复杂多样**的。（所以说"有其因必有其果"是错误的，因为相同的原因可能产生不同的结果。正确表述是"有因必有果"，只要有原因，就一定有结果，只要有结果，就一定有原因。）
- **方法论意义：**凡事预则立，不预则废。

#### （四）必然和偶然——第四对基本范畴

- **必然的概念：**指事物联系与发展过程中确定不移的趋势。
- **偶然的概念：**指事物联系与发展中并非确定发生的，可以出现，也可以不出现，可以这样出现，可以那样出现的不确定的趋势。
- **必然和偶然的关系：**
  - **相互区别：**
    1. 必然和偶然产生和形成的原因不同：必然产生于事物内部的根本矛盾；偶然产生于非根本矛盾的外部条件。
    2. 必然和偶然的表现形式不同：必然在事物发展过程中比较稳定，时空上比较确定；偶然是不确定的、暂时的。
    3. 必然和偶然在事物发展中的地位和作用不同：必然在事物发展中处于支配地位，决定着事物发展的方向；偶然居于从属地位，对发展的必然过程起促进或延缓作用。
  - **相互统一：**必然存在于偶然之中，要通过偶然表现出来，并为自己开辟道路；偶然背后藏着必然，受必然的支配，偶然是必然的表现形式和补充；一定条件下二者可相互转化。
- **方法论意义：**既要重视事物发展的必然，把握事物发展的总趋势，又要充分估计到各种偶然因素的作用，把握有利于事物发展的机遇。

> **关联**：必然性与偶然性的统一，也用于分析历史人物——任何历史人物的出现都是必然性和偶然性的统一（见「唯物史观」）。

#### （五）可能和现实——第五对基本范畴

- **可能的概念：**指事物发展过程中潜在的尚未实现的东西。
- **现实的概念：**相互联系着的实际存在着的事物的综合。
- **可能和现实的关系：**
  - 现实与可能相互区别，可能不等于现实，现实已经不是可能。
  - 现实与可能可以相互转化：
    1. 现实中蕴藏着未来的发展方向，会不断产生新的可能。
    2. 可能包含着发展现实的因素，一旦条件成熟，可能就会转化成现实。
- **方法论意义：**一方面要立足于现实，对可能性作出全面的分析和预判；另一方面要着眼长远，防止坏的可能变成现实，同时善于创造条件，促使好的可能获得实现。
- **区分可能和不可能的依据：**在现实中，是否有根据。（例如：你通过努力明年就能考上研究生——是可能；某天早上起来发现你家多了一只少女猫娘——是不可能。）
- **区分现实的可能和潜在（抽象）的可能：**在现实中的根据是否充分。（例如：你努力复习就能考上研究生——是现实的可能；某天晚上你只买了一张彩票，就中了一千万——是潜在的可能，也叫抽象的可能。）

### 六、客观辩证法和主观辩证法的统一

- **客观辩证法：**是指客观事物或客观存在的辩证法，即客观事物以相互作用、相互联系的形式呈现出各种物质形态的辩证运动和发展规律。（例如：就算是世界上的人都死光了，大自然还是按照自己的辩证法演绎，这种大自然的辩证法就是客观辩证法。说到底就是物质——具有第一性。即物质世界被意识世界反映。）
- **主观辩证法：**是指人类认识和思维运动的辩证法，即以概念作为思维细胞的辩证思维运动和发展规律。（世界上有了人以后，人们会观察，会思考。人们通过观察学会了大自然的客观辩证法，并应用客观辩证法去思考问题，形成的思维方式就是主观辩证法。说到底就是意识——具有第二性。即意识世界反映了物质世界。）

**唯物辩证法既包括客观辩证法又包括主观辩证法。客观辩证法和主观辩证法本质上是统一的，但在表现形式上是不同的。客观辩证法采取外部必然性的形式，即物质规律；主观辩证法采取观念的、逻辑的形式，即思维。**


唯物论和辩证法回答了“世界是什么、怎样存在”。认识论接着回答“人能不能认识世界、怎样认识世界”，重点是实践、认识和真理三者的关系。

# 第三章 实践与认识及其发展规律

## 认识论


### 一、实践的本质和基本特征

- **实践性**是马克思主义理论区别于其他理论的**根本特征**，也是马克思主义的**独有特性**。
- 人与世界的关系主要包括两个方面：一是认识世界（认识），二是改造世界（实践）。
- **关于实践错误的观点：**
  - 在中国古代哲学中，实践主要是指道德伦理行为（指人与人之间的关系和行为）——太狭隘了。
  - 康德把实践看成理性自主的道德活动——太狭隘了。
  - 黑格尔把实践理解成主体自我实现的精神活动（实践是一种物质活动）。
  - 费尔巴哈把实践与物质性的活动联系起来（这是他的进步）。但他把实践仅限于日常生活活动，并将实践等同于生物适应环境的活动（也就是他把实践仅仅看成人类的生理行为）。
- 马克思在《关于费尔巴哈的提纲》中提出：实践是**感性的**、**对象性的物质活动**，提出全部社会生活在本质上是实践的。
  - **感性：**实践要受到头脑的指挥，体现主体的目的、意愿和创造性。即能动性。
  - **对象性：**实践一定是指向某个客体的。
  - **物质活动：**实践具有物质性。
- **实践的基本特征：**
  - **客观实在性（也叫直接现实性）：**指实践具有能把我们脑中的物变成现实的物。
  - **自觉能动性：**指实践受头脑的指挥，体现着主体的目的、意愿和创造性。
  - **社会历史性：**指不同历史阶段，实践有不同的效果。

  （注：选择题中如果题干强调必须去做，如果不去做那么设计就不会变成现实，那么就是在说实践的**客观实在性**；如果题干中强调在做一件事之前必须先想好怎么做，那么就是在说实践的**自觉能动性**。）

### 二、实践的基本结构和形式

#### （一）实践的基本结构

实践的**主体**、**客体**和**中介**是实践活动的三项基本要素，三者的有机统一构成实践的基本结构。

- **实践主体**：指具有一定主体能力，从事现实社会实践的**人**。

实践主体的能力：

- **自然能力**——就是人的身体机能，如：长多高、力气有多大、耐力有多强。
- **精神能力**——就是人的感性思维和理性思维等精神层面的东西。
  - **知识性因素**——即学习能力（知识性因素是首要的能力）。
  - **非知识性因素**——欲望、信念等。

- **实践客体**：指实践活动所指向的对象。实践客体与客观存在的事物不完全等同，**客观事物只有被纳入主体实践活动的范围之内，为主体实践活动所指向并与主体活动相互作用时才成为现实的实践客体**。
- **实践中介**：是各种形式的工具、手段以及运用、操作这些工具、手段的程序和方法。可分为两个子系统：
  - 一是作为人的肢体延长、感官延伸、体能放大的物质工具系统。
  - 二是语言符号系统。
- 实践的主体和客体是相互作用的关系，这关系包括**实践关系**（即改造与被改造，是最根本的关系）、**认识关系**（即认识与被认识）和**价值关系**（即利用与被利用）。实践的主客体和认识的主客体本质上是一致的（因此我们说，实践和认识具有**同构性**，即结构相同）。

实践的主体、客体和中介是不断变化发展的，因而实践的基本结构也是随着历史的变化而发展的。这种变化主要表现为**主体客体化**和**客体主体化**的双向运动。

- **主体客体化**：是人通过实践使自己的本质力量作用于客体，使其按照主体的需要发生结构和功能上的变化，形成了世界上本不存在的对象物。

> 我根据我的需要，让我眼前的事物发生变化，为我所用。本质上是**客体**发生变化。

- **客体主体化**：是客体从客观对象的存在形式转化为主体生命结构的因素或主体本质力量的因素，客体失去客体性的存在形式，成为主体的一部分。

> 有一株天山雪莲，被我发现并服用，然后我变得更厉害了。本质上是主体发生变化。

#### （二）实践的形式

实践的形式可分为三种基本类型：物质生产实践（劳动）、社会政治实践（处理人与人的关系）、科学文化实践（对未知领域进行探索）。

三种实践类型的关系：相互区别又相互联系。物质生产实践是**最基本的实践活动**，构成全部社会生活的基础，其他两种实践是在物质生产实践基础上产生和发展的，受物质生产实践的制约并对其起能动的反作用。（即先有劳动，才有后面两个，后面两个发展得好也能提高劳动的效率。）

现代信息技术的发展，使得当代社会开始产生一种新的实践形式，即虚拟实践。虚拟实践是实践活动的**派生形式**，不是实践的基本形式，具有相对独立性。（虚拟实践指的就是人们通过互联网等结交朋友，进行买卖，甚至网恋等活动）

### 三、实践对认识的决定性作用

**实践是认识的基础**，实践在认识活动中起着决定性作用（说到底实践和认识的关系就是物质和意识的关系）。实践的观点是辩证唯物论的认识论之第一的和基本的观点。

**实践的观点的说法大总结：**

1. 实践的观点，是马克思主义首要的、基本的观点。
2. 实践性是马克思主义区别于其他理论的根本特性。
3. 实践的观点是认识论的第一和基本观点。

**实践对认识的决定性作用体现在：**

- **实践是认识的来源**（认识是多因素产生的，这些因素中，实践是决定性因素）。
- **实践是认识发展的动力**。
- **实践是认识的目的**，认识是为了实践而认识。
- **实践是检验认识真理性的唯一标准**。马克思说："人的思维是否具有客观的真理性，这不是一个理论的问题，而是一个实践的问题。人应该在实践中证明自己思维的真理性，即自己思维的现实性和力量，自己思维的此岸性。"（实践和认识中间隔着一条河流，实践和认识分居河的两岸。我得到了一个认识，如果我只在此岸去研究认识到底对不对是不会有结果的，一定要到彼岸，到实践那边去验证认识的正确性。）

### 四、认识的本质

**几种认识观：**

1. 二元论（不彻底的唯心主义）：物质和意识都是世界的本原，最终导致世界的不可知论，即**世界是不可以被认识的**。
2. 唯心主义（不包括不彻底的唯心主义二元论）：认为意识是世界的本原，物质从意识中派生出来。即认识的过程是从感觉思想到物质（先验论）。
3. 唯物主义：认为物质世界是世界的本原，意识从物质中派生出来。即认识的过程是从物质到感觉思想（反映论）。

但是反映论内部也有分歧：

- 直观、机械的反映，即眼前是什么样子的，脑子里就是什么样子的，也就是旧唯物主义持有的观点（除了马克思的唯物主义之外剩下的唯物主义都叫旧唯物主义），坚持反映论的同时抹杀了能动性。
- 能动反映——马克思主义哲学，也叫辩证唯物主义哲学（正确的观点）。

**能动反映论**：认为认识的本质是主体在实践基础上对客体的能动反映，这种反映不但具有反映客体内容的反映性特征，而且具有实践所要求的主体能动的、创造性的特征。

- 一方面，认识的反映特性是人类认识的基本规定性。指人的认识必然要以客观事物为原型或摹本，在思维中再现或摹写客观事物的状态。（批判了二元论和唯心主义）
- 另一方面，认识作为能动作用具有创造特性，认识是一种在思维中能动的、创造性的活动，而不是主观对客观对象简单、直接的临摹或照镜子式的原物重现。（批判了旧唯物主义）

**认识的反映特性和创造特性的关系**：不可分割。反映和创造不是人类认识的两种不同的本质，而是同一本质的两个不同的方面。

认识论的问题上，马克思既看到了反映，又看到了创造。只看反映不看创造导致旧唯物主义，只看创造不看反映导致不可知论和唯心主义。

**能动反映论的两个突出优点：**

- 把实践的观点引入认识论。
- 把辩证法应用于反映论考察认识的发展过程，把认识看成一个由不知到知，由浅入深的充满矛盾的能动的认识过程。

### 五、认识的过程（两次飞跃）

从考试的角度来说，第一次飞跃更重要。但从飞跃的角度来说，第二次飞跃更重要。

#### （一）从实践到认识（感性认识到理性认识的飞跃）

- **感性认识**：是人们在实践基础上，由**感觉器官直接感受到**的关于事物的现象、事物的外部联系、事物的各个方面的认识，包括**感觉**、**知觉**和**表象**三种形式。
  - **感觉**：外部事物作用于我们的感觉器官产生的第一感受。
  - **知觉**：众多感觉组成，形成的我们对于一个事物的整体认识。
  - **表象**：根据知觉形成的对一个事物的印象。

感性认识是认识的**初级阶段**，具有**直接性**、**具体性**的突出特点。

- **理性认识**：是认识的高级阶段，是人们借助抽象思维，在概括整理大量感性材料的基础上，达到关于事物的本质、全体、内在联系和事物自身规律性的认识。包括**概念**、**判断**和**推理**三种形式。
  - **概念**：是思维的细胞，是思考的单位。
  - **判断**：有了概念才会根据概念进行判断。
  - **推理**：有了判断才能对事物进行推理。

理性认识具有**间接性**和**抽象性**。

- **感性认识和理性认识的关系——辩证统一：**
  - 理性认识依赖于感性认识，感性认识是认识过程的起点。
  - 感性认识有待于发展和深化成理性认识。感性认识和理性认识相互渗透，相互包含。
    - 一方面，感性中有理性，人的感觉是渗透着理性的感觉。
    - 另一方面，理性中有感性，理性不仅以感性材料为基础，而且也以文字符号等感性形式的语言作为表达手段。

- **实现飞跃的基本条件：**
  - 投身实践，深入调查，获得十分丰富和合乎实际的感性材料。
  - 运用理性思维和科学实践，对丰富的感性材料去伪存真，形成概念和理论系统。

过分强调理性认识，忽略感性认识是教条主义、唯理论；过分强调感性认识，忽略理性认识是经验主义、经验论。

#### （二）从认识到实践的飞跃（理性认识到实践的飞跃）

是认识过程的第二次能动的飞跃，是更为重要的一次飞跃。

### 六、认识过程中的影响因素

- **理性因素**：指人的理性直观、理性思维能力。它的作用主要有**指导**、**解释**和**预见**作用。
- **非理性因素（感性因素）**：指认识主体的情感和意志，如联想、想象、猜测等。非理性因素对于人的认识能力和人的活动具有激活、能动作用。

### 七、认识的两大规律（反复性和无限性）

- **反复性**：指人们对于一个复杂事物的认识往往要经过由感性认识到理性认识，再由理性认识到实践的多次反复才能完成。原因：
  - 从客观方面来讲，事物的各个侧面及其本质的暴露有一个过程。
  - 从主观方面来讲，人的认识也有一个提高的过程。
- **无限性**：指对于事物发展过程的推移来说，人类的认识是永无止境、无限发展的，表现为"实践——认识——再实践——再认识"的无限循环（否定之否定规律）。

### 八、真理及其特性

- **真理：**是人们对客观事物及其规律的**正确**反映。（把"正确"两个字改成"错误"就是**谬误**的定义）

**真理的特点：**

- **客观性**——凡是真理都是客观真理，具有两层含义：
  - 真理的内容是客观的。
  - 真理的标准是客观的。

  （注：真理的形式是主观的。所以大体上说真理是客观的，但是说真理有主观的一面是对的）。承认真理的客观性，就是坚持了真理问题上的唯物主义。

  **错误观点（主观真理论）：**
  1. 马赫主义认为真理是"思想形式"，凡是多数人承认的就是真理。
  2. 实用主义认为"有用即真理"。

- **一元性**（由客观性决定的特点）——对同一事物的不同认识最多只能有一个是真理。
- **绝对性**（与相对性相对立）——指真理主客观统一的确定性和发展的无限性，具有两层含义：
  - 任何真理都必然包含同客观对象相符合的客观内容，都同谬误有原则的界限。否则就不能称其为真理。这一点是无条件的，绝对的。
  - 按人类认识的本性来看，我们能够正确认识无限发展着的物质世界，认识每前进一步，都是对无限发展着的物质世界的接近，这一点也是无条件的，绝对的。
- **相对性**——人们在一定条件下对客观事物及其本质和发展规律的正确认识总是有限的、不完善的，有两层含义：
  - 从客观世界的整体来看，任何真理都是对客观世界的某一阶段、某一部分的正确认识，认识有待扩展。
  - 就特定事物而言，任何真理都只是对客观对象一定方面、一定层次和一定程度的正确认识，认识有待深化。

  所以任何真理都只能是主观对客观事物近似正确即相对正确的反映。

**真理的绝对性和相对性的关系：**

- **相互依存**——没有你就不能有我，没有我就不能有你。
- **相互包含**——你中有我，我中有你，任何真理的相对性之中都包含绝对性的颗粒（就是相对正确的真理里面肯定有一部分是绝对正确的）。

**真理发展规律：**人类的认识是一个不断深化的过程，永远处在由真理的相对性走向绝对性、接近绝对性的转化和发展过程中。任何真理性的认识都是由真理的相对性向绝对性转化过程中的一个环节。它既是以往实践和认识达到的终点，又是进一步迈向真理绝对性的起点。（所以无数相对真理总和构成绝对真理这个说法是对的）

**为什么真理既有绝对性又有相对性：**真理的绝对性和相对性根源于人的认识能力、思维能力的矛盾本性，是人的思维的至上性和非至上性或人的认识能力的无限性和有限性的矛盾。

- **至上性（无限性）**：即人类完全有能力认识世界的一切。由于至上性，所以真理有绝对性。
- **非至上性（有限性）**：即目前人类还不能完全认识世界。由于非至上性，所以真理有相对性。

**错误观点：**

- 过分夸大绝对真理，抛弃相对真理：教条主义、思想僵化。
- 过分夸大相对真理，抛弃绝对真理：怀疑主义、诡辩论。

### 九、真理和谬误

**辩证关系：**

- 真理和谬误相互对立。
- 真理和谬误的对立是相对的，他们相互依存、相互转化。真理和谬误相比较而存在，没有真理就没有谬误，没有谬误也就没有真理。真理中包含着某种以后会暴露出来的错误的方法或因素，谬误中也存在着以后会显露出来的真理的萌芽。**在一定条件下，真理和谬误可以相互转化。**真理和谬误在**一定范围内**的对立是绝对的，超出了这个范围，他们就会相互转化，真理变成谬误，谬误变成真理。

### 十、真理的检验标准

实践是检验真理的唯一标准，原因：这是由**真理的本性**（即主客观相一致）和**实践的特点**（直接现实性的特点，即它能把主客观联系起来，客观变主观，主观变客观）决定的。

实践是检验真理的唯一标准，并不排斥逻辑证明的作用。逻辑证明是探索真理、论证真理和扩大真理范围的重要手段，是对实践的一个重要补充，但不是检验真理的标准，因为：

- 逻辑是从实践中得来的。
- 依赖的前提假设不一定是真的。

**实践标准的确定性与不确定性：**

- **确定性（即绝对性）：**
  1. 实践是检验真理的唯一标准，此外再无别的标准。
  2. 凡经过实践证明了的一切认识都是客观真理，都具有不可推翻的性质。
  3. 实践能够检验一切认识，即便当前的实践还不足以加以判断，最终也会被以后的实践作出判决。
- **不确定性：**
  1. 一定历史阶段上的具体实践具有局限性，它不能验证所有真理。
  2. 实践检验真理不是一次完成的。
  3. 已经被实践验证的真理，以后还要再验证。

实践不断发展，真理也会不断发展，在发展的实践中不断验证认识的真理性，这就是实践检验真理的辩证发展过程。

### 十一、真理与价值的辩证统一

**价值的基本特性：**

- **主体性**：因人而异，即对于不同人来说，一个事物的价值大小不一样。
- **客观性**：不以人的意志为转移。即不论你怎么想，这个东西有价值就是有价值。
- **多维性**：价值对不同维度的人来说不一样。
- **社会历史性**：不同历史时期事物的价值不一样。

**补充：认识**

- **知识性认识**：主体对客体本身进行认识。例如一个苹果放在你面前问你这是什么，你回答对了是真理，回答错了是谬误。
- **评价性认识**：主体对主客体之间的关系进行认识。例如一个苹果放在你面前问你喜不喜欢，想不想要。

**价值评价的特点及标准：**价值评价是一种关于价值现象的认识活动，是主体对客体的价值以及价值大小所作的评判，因而也被称为价值判断。基本特点：

- 评价以主客体的价值关系为认识对象。
- 评价结果与评价主体直接相关。
- 评价结果的正确与否取决于对客体的状况和主体需要的认识。即评价的正确依赖于知识性认识。
- 价值评价也有科学与非科学之说，即价值评价也有对错。评价作为一种价值判断活动，具有主观性，但并不是一种主观随意的认识活动，只有正确反映价值关系的评价才是正确的评价。价值评价要以真理为标准，要有利于人类主体的生存和发展，与社会历史发展的客观规律相一致，推动社会历史进步，以最广大人民的需要和利益为根本。

**真理与价值的关系：**人们的实践活动总是受到真理尺度和价值尺度的制约，任何实践活动都要在这两种尺度共同制约下进行的，任何成功的实践都是真理尺度和价值尺度的统一。一方面，价值尺度必须以真理为前提，另一方面，人类自身需要的内在尺度，推动着人们不断发现新的真理。

> 补充：唯物论中，实践既要遵循规律（真理尺度，也是前提），又要发挥能动作用（价值尺度）。

### 十二、从必然走向自由

- **自由**：是表示人的活动状态的范畴，是指人在活动中通过认识和利用必然所表现出的一种自觉自主的状态。（就是能动性的意思）
- **必然**：必然性即规律性，是指不依托于人的意识而存在的自然和社会发展所固有的客观规律，自由是对必然的认识和对客观世界的改造。（就是规律性的意思，所以必然是前提）

**错误观点：**完全夸大自由，贬低必然，犯了唯意志论；过分夸大必然，贬低自由，犯了宿命论的错误。

**认识必然和争取自由**，是人类认识世界和改造世界的**根本目标**。是一个历史性的进程。一部人类发展史就是不断从必然王国走向自由王国的过程（在原始社会，人类被大自然主宰，随着人类认识世界和改造世界，把大自然的规则为自己所用，走向自由）。

马克思认为，自由是人类历史的产物，自由是有条件的：

- **认识条件**——人的认知越多越自由。
- **实践条件**：
  - 自由要以必然为前提。
  - 自由要以不牺牲别人的自由为前提。

> **关联**：人类从必然王国走向自由王国，正是社会进步的重要标志；唯物史观把人的发展（自由度的提高）作为社会进步的重要标志，并将其划分为三个阶段（见「唯物史观」）。


认识论讲的是人如何认识世界；唯物史观把视角推到社会历史领域，回答社会发展的规律、动力和主体。

# 第四章 人类社会及其发展规律

## 唯物史观


### 一、唯物史观与唯心史观的对立

社会历史观的基本问题：**社会存在**和**社会意识**的关系问题。

> **关联**：哲学基本问题是物质和意识的关系问题（见「唯物论」）。所以社会历史观的基本问题就是哲学基本问题在社会历史领域的延伸——社会存在即社会历史领域中物质的东西，社会意识即社会历史领域中意识的东西。

**唯心史观的缺陷：**

- 一是考察了人的活动的思想动机，却没有考察思想动机背后的物质动因和经济根源。（即唯心主义认为历史是人的思想决定的。对应的，唯物史观认为历史是物质力量决定的，即由当时的社会生产力和社会生产关系决定）
- 二是只看到个人在历史上的作用，忽视了**人民群众是历史的创造者**。（因此，唯心史观也被称作英雄史观。唯物史观认为个人在历史上确实起到了作用，但个人起的作用不是决定性作用。）

> **关联**：以上两点缺陷，分别对应对"社会存在与社会意识谁决定谁"的回答（即唯物史观与唯心史观的**根本分野**，见「二」）和对"谁是历史创造者"的回答（即二者的**分水岭**，见「八」）。

### 二、社会存在与社会意识的辩证关系

**社会存在：**

- **自然地理环境**：自然地理环境优渥与否，是否宜居。仅是有影响，起不到决定性作用。
- **人口因素**：人口的数量、质量、结构等，仅是有影响作用。
- **物质生产方式**：起决定性作用，由两部分构成：
  - **生产力**（物质生产方式中的决定性因素，所以可以说它是**社会历史领域中的至高概念**，只要它作主语，后面的说法多么绝对都是正确的。甚至说，单选题里四个选项分别是四个概念，只要选项讲生产力就一定选它）。
  - **生产关系**

> **辨析（低级概念）**：自然地理环境和人口因素都属于"低级概念"——考试时把这两个因素夸大为决定性因素是错误选项，忽视这两个因素也是错误选项。

**社会意识：**

- **社会心理**：人们的风俗习惯、情感、情绪等，即相对浅层次的、感性的、非理论化的东西。
- **社会意识形式**：相对理性的、深层次的、系统化的东西。我们根据这个形式与阶级、经济、物质利益是否有关，又把它区分为：
  - **社会意识形态**
  - **非社会意识形态**

（所谓与阶级有关，就是不同阶级对这个东西的看法不一样；与阶级无关，就是所有阶级对这个东西看法都一样。我们日常接触的文科、社会学科都属于社会意识形态，语言学、自然科学等属于非社会意识形态。）

**社会存在与社会意识的辩证关系原理的内容及意义：**

1. 社会存在决定社会意识，社会意识是社会存在的反映，并反作用于社会存在。具体表现在三个方面：
   - 社会存在是社会意识内容的客观来源，社会意识是社会物质生活的主观反映。
   - 社会意识是人们物质交往的产物。
   - 随着社会存在的发展，社会意识也相应地**或迟或早**地变化和发展。（即社会存在一旦发生变化，社会意识必须要变，但不是立刻变。所以说法"社会存在的变化会立刻在社会意识中反映出来"是错误的。）
2. 社会存在和社会意识辩证关系的另一个方面，是社会意识具有**相对独立性**：
   - 社会意识与社会存在发展具有不完全同步性和不平衡性。
   - 社会意识内部各种形式之间存在相互影响且各自具有历史继承性。
   - **社会意识对社会存在有能动的反作用。**（社会意识相对独立性的最突出表现）先进的社会意识对社会发展起促进作用；落后的社会意识对社会发展起阻碍作用。

> **关联**：社会意识的"相对独立性"及其"反作用"，正是唯物论中"意识对物质具有相对独立性和能动反作用"在社会历史领域的具体体现（见「唯物论」）。

主张社会存在决定社会意识，还是社会意识决定社会存在，是**唯物史观和唯心史观的根本分野**。

> **辨析**：**根本分野**（本节）针对"社会存在与社会意识谁决定谁"；**分水岭**（见「八」）针对"人民群众还是英雄创造历史"，二者不可混淆。

### 三、生产力和生产关系矛盾运动的规律（社会历史领域第一对基本矛盾）

**生产力**：在哲学上，生产力是标志人类改造自然的实际程度和实际能力的范畴，表示**人与自然的关系**。由三部分构成：

- **劳动资料**（即劳动手段）。其中最重要的是**生产工具**，它是生产力发展水平的客观尺度，是区分**社会经济时代的客观依据**。
- **劳动对象**。（劳动资料 + 劳动对象 = 生产资料）
- **劳动者**：是生产力中最活跃的因素，生产资料和劳动者相结合，才能变成现实生产力。在现代生产中，脑力劳动者的质量和数量日益具有决定性意义；在高新技术领域，脑力劳动和体力劳动具有**直接同一的趋势**（所以我们也能说：生产力是生产资料和劳动者的统一。）

在现代，科学技术日益成为生产发展的决定性因素。科学技术是先进生产力的集中体现和主要标志，是第一生产力。

> **辨析**：科学技术到底能不能起决定性作用要看语境——在生产劳动中，科技起决定性作用；在社会历史发展中，生产力和生产方式才起决定性作用，科技只是影响因素（另见「七」）。

**生产关系**：是人们在物质生产过程中形成的**不以人的意志为转移**的经济关系（所以生产关系是一种物质）。是社会关系中**最基本的关系**。

狭义的生产关系是在直接生产过程中结成的相互关系，包括：

- **生产资料所有制关系**（决定性）。
- **生产中人与人的关系**。
- **产品分配关系**。

在生产关系中，生产资料所有制是最基本的、决定性的。它构成全部生产关系的基础，是**区分不同生产方式、判定社会经济结构的客观依据**（社会经济结构：即奴隶社会、封建社会等）。

**生产力和生产关系的辩证关系**：社会生产中，生产力是生产的物质内容，生产关系是生产的社会形式。二者的有机统一构成社会的生产方式。生产力与生产关系的相互关系为：生产力决定生产关系，生产关系反作用于生产力。

生产力与生产关系的矛盾运动中内在的、本质的、必然的联系，就是**生产关系一定要适合生产力状况的规律**。这个规律就是人类社会发展的基本规律，也称第一规律。

> **辨析**：此处的"第一规律"指的是**人类社会历史发展的基本规律**；不要与唯物辩证法的"第一规律"（对立统一规律）混淆（见「唯物辩证法」）。

### 四、经济基础和上层建筑矛盾运动的规律（社会历史领域第二对基本矛盾）

**经济基础**：是由社会一定发展阶段的生产力所决定的**生产关系**的总和。（所以说，经济基础就是生产关系。而生产力决定生产关系，因此也可以说生产力决定经济基础。）

> **关联**：经济基础$=$生产关系，因此"生产力决定生产关系"也即"生产力决定经济基础"（见「三」）。

**上层建筑**：建立在一定经济基础之上的**意识形态**（观念上层建筑）以及与之相应的**制度、组织和设施**（政治上层建筑，如军队、法律、监狱、政党等）。

> **关联**：此处的"意识形态"即社会意识中的**社会意识形态**（见「二」）。

**观念上层建筑与政治上层建筑的关系**：政治上层建筑在一定意识形态指导下建立，是统治阶级意志的体现；政治上层建筑一旦形成，就成为一种现实的力量，影响并制约人们的思想理论观点。

在整个上层建筑中，**政治上层建筑**居主导地位，**国家政权**是其核心；而在观念上层建筑中，**政治法律思想**是其核心。

**经济基础与上层建筑的辩证关系：**

- 经济基础决定上层建筑。
- 上层建筑对经济基础具有反作用。体现在：上层建筑为自己的经济基础的形成和巩固服务，确立或维护其在社会中的统治地位。上层建筑反作用的性质，取决于它服务的经济基础的性质。归根到底取决于它是否有利于生产力的发展。

（判断一个上层建筑先不先进，不是看它是否适应经济基础的发展，而是看它服务的经济基础能否适应生产力的发展。）

**经济基础与上层建筑的矛盾运动及其规律**：经济基础和上层建筑相互作用构成二者的矛盾运动规律，这个规律就叫**上层建筑一定要适合经济基础状况的规律**（人类社会历史发展的第二规律）。

> **辨析**：此"第二规律"是**人类社会历史发展的基本规律**，与唯物辩证法的"第二规律"（量变质变规律）不是一回事（见「唯物辩证法」）。

### 五、人类普遍交往与世界历史的形成发展

**交往**：一定历史条件下人与人、社会与社会、国家与国家、民族与民族的来往。

**交往与生产力的关系**：交往是与生产力的发展相伴随的，交往是人类实践活动的重要组成部分，对社会生活有着重要的影响：

1. 促进生产力的发展。
2. 促进社会关系的进步。
3. 促进文化的发展与传播。
4. 促进人的全面发展。

**世界历史的形成与发展**：生产方式的发展变革是世界历史形成和发展的基础。普遍交往是世界历史的基本特征。人类历史向世界历史的转变是资本主义生产方式出现和向世界扩张的结果。世界历史的形成又反过来促进了生产力的普遍发展和人类的普遍交往。

### 六、社会进步与社会形态的更替

**社会进步**主要表现在两个方面：

- 一是社会形态从低级到高级的发展。（所谓社会形态是指：原始社会$\rightarrow$奴隶社会$\rightarrow$封建社会$\rightarrow$资本主义社会$\rightarrow$共产主义社会。这样五个社会发展阶段由低到高。社会主义社会是共产主义社会的初级阶段，本身并不是独立的社会形态。）
- 二是同一社会形态内部的发展。

**人的发展**：即人的体力、智力、个性和交往能力等的发展，最根本的是**人的自由度的提高**。人的发展程度构成了**社会进步**的重要标志。唯物史观把人的自由度分成三个阶段：

- **人的依赖关系占统治地位的阶段**：即例如奴隶社会，奴隶是依赖于奴隶主的，整个人都是奴隶主的所有物，没有自由。
- **物的依赖关系为基础的人的独立性的阶段**：到资本主义以后，人相比以前的社会取得了极大的解放，每个人在社会中是一个独立的个体，表面上看获得了自由。但此时人并没有真正获得自由，因为人此时处于物的依赖，即人为了维持自己的生活所需，需要出卖自己的劳动力获得报酬。
- **自由个性的阶段**：共产主义社会，物质财富极大丰富，人们不再会为了谋生而不得不做自己不愿意做的事。

只有在共产主义社会，人才能真正得到全面而自由的发展。

> **关联**：这里的"人的发展 / 自由度的提高"，与认识论中"从必然走向自由"（自由是对必然的认识和对客观世界的改造）相通（见「认识论」）。

**社会形态**：是关于社会运动的具体形式、发展阶段和不同质态的范畴，是**同生产力发展一定阶段相适应的经济基础和上层建筑的统一体**。

（社会形态$=$经济基础（经济形态） $+$上层建筑（政治上层建筑——政治形态$+$意识上层建筑——意识形态，也叫文化）。）

**社会形态更替的特点：**

- **统一性和多样性**：
  - 统一性：不论是世界上任何一个地方的人类社会，都要经过这个阶段。
  - 多样性：不同地方的人类社会的社会形态更替又有自己的特点。从纵向看，不同的民族可以超越一种或几种社会形态跳跃式地向前发展；从横向看，现实社会中，每一种社会形态在不同的民族那有自己的特殊表现形式。
- **必然性和选择性**：
  - 必然性：就是规律性。
  - 选择性：就是过程中人的能动性。

  人们的历史选择性包含三层意思：
  1. 社会发展的必然性造成了一定历史阶段社会发展的基本趋势，为人们的历史选择性提供了可能性空间。即例如，当一个社会处于封建社会的时候，可能性空间就包括：资本主义社会和社会主义社会。人们可以根据自身需要选择其中一个。
  2. 社会形态更替的过程，是一个主观能动性和客观规律性统一的过程（就是既要顺应规律又要发挥能动）。
  3. 所谓人民的选择说到底是人民群众的选择，最终取决于**人民群众的根本利益、根本意愿以及对社会发展规律的把握和程度**。
- **前进性和曲折性**：
  - 前进性：所有人类社会都要往前走。
  - 曲折性：有些国家的有些地方的人类社会可能出现暂时性的倒退。

> **关联**：社会形态更替的"必然性和选择性"，即唯物论中"主观能动性和客观规律性的统一"在社会历史领域的体现（见「唯物论」）；"前进性和曲折性"与唯物辩证法中否定之否定规律所揭示的"波浪式前进、螺旋式上升"一脉相承（见「唯物辩证法」）。

### 七、社会历史发展的动力

**社会历史发展的动力：**

- **社会基本矛盾**——历史发展的根本动力（最重要）。对历史发展的作用表现在：
  - 生产力是社会基本矛盾中最基本的动力因素，是人类社会进步的终极决定力量。
  - 社会基本矛盾，尤其是生产力与生产关系之间的矛盾（第一对基本矛盾）是**"一切历史冲突的根源"**，决定着**其他矛盾的存在和发展**。
  - 社会基本矛盾有不同的表现形式和解决方法，并从根本上影响和促进社会形态的变化和发展。
- **阶级斗争和社会革命**——重要动力。
- **改革**——重要动力。
- **科学技术**——重要动力。现代科学技术革命对人类社会发展的影响：
  - 对生产方式产生深刻影响。
  - 对生活方式产生巨大影响。
  - 促进了思维方式的变革。
- **文化**——重要动力。

> **辨析**：社会基本矛盾是**根本动力**，阶级斗争和社会革命、改革、科学技术、文化都是**重要动力**，注意区分"根本动力"与"重要动力"（选择题常考）。另：科学技术的作用要看语境——在生产劳动中是决定性因素，在社会历史发展中只是影响因素（见「三」）。

### 八、关于历史创造者的问题

究竟是谁创造了历史？是**人民群众创造历史还是英雄创造历史**，这是唯物史观和唯心史观的**分水岭**。

> **辨析**：勿与"**根本分野**"混淆——根本分野是社会存在决定社会意识，还是社会意识决定社会存在（见「二」）；分水岭是人民群众创造历史，还是英雄创造历史。

**唯物史观考察历史创造者的原则：**

- 唯物史观立足于现实的人及其本质来把握历史的创造者。马克思指出："人的本质不是单个人所固有的抽象物，在其现实性上，它是**一切社会关系的总和**。"即人的本质属性在于**人的社会属性**，而不是自然属性。
- 唯物史观立足于**整体的社会历史过程**探究谁是历史的创造者。（对于某个历史事件来说，肯定是英雄人物创造历史。而这就不是马克思主义哲学研究的东西，因为谁谁谁干了什么只是一个小插曲，影响不了整体的历史进程。）
- 唯物史观从**社会历史的必然性**出发考察谁是历史的创造者。即谁在顺应规律，谁就是历史的创造者。
- 唯物史观从**人和历史关系的不同层次上**考察谁是历史的创造者。即唯物史观既看到了群众的整体作用，也看到了英雄的作用。

### 九、人民群众创造历史

**人民群众是一个历史范畴。**从质上说，人民群众是指一切对社会历史发展起推动作用的人；从量上说，人民群众是指社会人口中的绝大多数。在不同历史时期，人民群众有着不同的内容，包含着不同的阶级、阶层和集团。但它最稳定的主体部分始终是**从事物质资料生产的劳动群众**。

在社会历史发展过程中，人民群众始终起着决定性作用。原因在于：

- 人民群众是社会物质财富的创造者。
- 人民群众是社会精神财富的创造者。
- 人民群众是社会变革的决定性力量。
- 人民群众既是先进生产力和先进文化的创造主体，也是实现自身利益的根本力量。

历史是人民群众创造的，但人民群众创造历史的活动又受到了一定社会历史条件的制约，包括经济条件、政治条件和精神文化条件。

**方法论（无产阶级政党的群众路线）**：应该坚持群众观点和群众路线。（这些在后面毛中特的部分中会详细讲述。）

> **关联**：本节是唯物史观对"谁是历史创造者"的正面回答，也正是它与唯心史观（英雄史观）"分水岭"所在（见「一」「八」）。

### 十、个人在历史的作用（英雄人物在历史的作用）

**杰出人物**是历史人物中对推动历史社会发展做出重要贡献或起重要作用的人。

**不管是什么样的历史人物，在历史上发挥什么作用，都要受到社会发展客观规律的制约，而不能决定和改变历史发展的总进程和总方向。**

**任何历史人物的出现都体现了必然性和偶然性的统一。**历史发展到一定阶段后，必然呼唤历史英雄人物的出现，但偶然性在于英雄人物是这个人，而不是那个人。

> **关联**：此处"必然性和偶然性的统一"，与唯物辩证法五大基本范畴中的"必然和偶然"是同一对范畴的具体运用（见「唯物辩证法」）。

**辩证地理解和评价个人的历史作用**：历史人物的作用取决于他们的思想、行为是否符合社会发展规律，是否符合人民群众的意愿。

**无产阶级领袖**所代表的是历史上最革命、最先进的阶级，在革命和建设中发挥了重大作用。但是他们也会犯错，也会因为决断失误导致违背历史发展（例如赫$X$晓夫），所以说法"无产阶级领袖一定起着正面作用"是错误的。所以我们在分析他们的时候也要把握历史分析方法和阶级分析方法：一方面，高度肯定他们的伟大功绩，另一方面，也要指出他们在认识和行动上存在的历史局限性，包括不回避他们的失误和错误。

**群众、阶级、政党、领袖的关系**：群众是最庞大的存在，群众内部分成不同阶级，不同阶级由不同政党代表，不同政党需要领袖来主持。

# 第五章 资本主义的本质及规律

## 简单商品经济

### 总纲

本部分围绕**价值**这一主线展开，依次回答四个问题：

1. **价值是什么** —— 商品的二因素与生产商品的劳动二重性
2. **价值如何衡量** —— 劳动时间尺度与劳动生产率
3. **价值如何表现** —— 价值形式的发展与货币
4. **价值有何规律** —— 价值规律

最后说明以私有制为基础的商品经济的基本矛盾，以及劳动价值论的意义。

### 一、价值是什么

- **商品经济**：是**以交换为目的**而进行生产的经济形式。产生的两个社会历史条件：一是**社会分工的存在**；二是**生产资料和劳动产品属于不同的所有者**。

- **商品**：用来交换、能满足人们某种需要的劳动产品，具有**使用价值**和**价值**两个因素。

- **使用价值**：指商品能满足人的某种需要的属性，即商品的有用性。它反映了人与自然的物质关系，是商品的**自然属性**，也是一切劳动产品共有的属性。使用价值构成社会财富的物质内容。（考研政治中：社会财富 = 使用价值，而不等于价值）

- **价值**：价值是凝结在商品之中的无差别的**劳动**，即人的脑力和体力的耗费；是商品所**特有**的**社会属性**。（即为了把商品生产出来所耗费的劳动，因此天然存在的东西如空气没有价值。价值一定是在人与人之间、在交换中产生的，所以即便是劳动所得，不经交换也没有价值。）

- **交换价值**：使用价值是交换价值的物质承担者。交换价值首先**表现**为一种使用价值对另一种使用价值相交换的量的关系和比例。**决定**商品交换比例的，不是商品的使用价值，而是**价值**。（例如，假设现在有这么个交换关系：一只鼠标可以换两支笔，从表面上看，好像一只鼠标的用途和两支笔相当，所以鼠标和笔能一换二；但是决定鼠标和笔一换二的不是它们的用途，而是它们的价值。）

- **使用价值和价值的关系**：对立统一。
  - **不可兼得**：你不可能同时得到一个商品的价值和使用价值——卖出这个商品时，你得到了它的价值，却得不到它的使用价值；买下这个商品时，你得到了它的使用价值，却付出了它的价值。
  - **缺一不可**：少了任何一个，这东西都不是商品。

> **辨析：哲学中的"价值"与政治经济学中的"价值／使用价值"是两码事**
>
> 如果道友们有做好充分复习的话，会发现"价值"这个概念在前面的马克思主义哲学中"真理和价值的统一"那个地方也有提到。哲学的价值强调的是一个自然界中的物质是否对人有用，例如人需要氧气和水才能存活，所以在哲学的角度来看，自然界的氧气和水是有价值的。而在政治经济学中，不论是价值还是使用价值都是针对于商品而言的，自然界中的氧气和水是没有人的劳动参与产出的，所以也就没有价值和使用价值这么一说。哲学的价值和政治经济学的价值$or$使用价值是两码事。

- **具体劳动**：生产一定使用价值的**具体形式的劳动**。

- **抽象劳动**：撇开一切具体形式的、无差别的**一般人类劳动**，即人的体力和脑力的耗费。

- **劳动的二重性决定了商品具有两个因素**：因为是**具体劳动**，所以劳动生产的商品具有**使用价值**；因为是**抽象劳动**，所以劳动生产的商品具有**价值**。
  - （不同人劳动的形式不同：老师讲课动的是嘴皮子，环卫工人扫大街动的是手和眼睛，就算是鸡也得张开腿。从这个角度上说，具体劳动是有差别的，因此劳动产生的商品才有不同的使用价值。）
  - （但是不论是谁的劳动，都是人类脑力和体力的耗费，这是所有劳动的共性，因此价值因素是所有商品共有的。）

- **具体劳动和抽象劳动的关系**：它们是**同一劳动的两种规定**。即任何一个劳动既是具体劳动，又是抽象劳动，关键看角度。

- **小结**：具体劳动创造商品的使用价值，抽象劳动形成商品的价值。（抽象劳动 = 价值）

### 二、价值如何衡量

价值就是劳动，所以衡量价值肯定要通过劳动来衡量，但是选择什么衡量尺度呢？这个衡量尺度一定要是客观的、可衡量的。所以我们一般采用：生产这种商品全社会的人所需要的平均劳动时间作为衡量标准。即决定商品价值量的不是个别劳动时间，而是**社会平均劳动时间**（即社会必要劳动时间）。

**商品价值量的决定：**

- **社会平均劳动时间**：在现有社会正常的生产条件下，在社会平均的劳动熟练程度和劳动强度下，制造某种使用价值所需要的劳动时间。
- 商品的价值是凝结在商品中无差别的一般人类劳动。
- 商品价值量由劳动者生产商品所耗费的劳动量决定。

**商品价值量与劳动生产率的关系：**

当全社会的劳动生产率提高一倍和个别的劳动生产率提高一倍时：

| 项目 | 单位商品的价值量 | 单位时间内生产的商品数量 | 单位时间内生产的商品价值总量 | 单位商品的使用价值量 | 单位时间内生产的商品的使用价值总量 | 单位时间内生产的社会财富总量 |
| --- | --- | --- | --- | --- | --- | --- |
| **全社会劳动生产率提高一倍** | 降低一倍 | 提高一倍 | 不变 | 不变 | 提高一倍 | 提高一倍 |
| **个别劳动生产率提高一倍** | 不变 | 提高一倍 | 提高一倍 | 不变 | 提高一倍 | 提高一倍 |

> 注：单位时间内生产的商品价值总量 = 单位商品的价值量 × 单位时间内生产的商品数量；单位商品的使用价值量与生产商品的快慢无关；社会财富 = 使用价值。

**结论**：商品的价值量与生产商品所耗费的**社会必要劳动时间成正比**，与**劳动生产率成反比**。

**影响劳动生产率的因素**（均与之成**正比**）：

- 劳动者的平均劳动熟练程度。
- 科技的水平及其应用。
- 生产过程的社会结合（就是分工）。
- 生产资料的规模和效能以及自然条件等。

**简单劳动和复杂劳动：**

- **简单劳动**：不需要经过专门训练，或者说只需要很短的时间学习和训练就能进行的劳动。
- **复杂劳动**：需要经过专门的训练和学习才能进行的劳动。
- 商品的价值是以简单劳动为尺度计量的，**复杂劳动等于自乘或多倍的简单劳动**。（自乘：指简单劳动和复杂劳动的换算比例不需要人为干预，由市场自发进行调控。）

### 三、价值如何表现

因为你看到商品的时候，是看不出来生产这个商品的人花费了多少时间的，所以价值必须通过**交换**表现出来。

**商品的价值形式发展的四个阶段：**

1. **简单的或偶然的价值形式** —— 商品价值的初级外化形式：用另一个商品的价值来表达它的价值。
2. **总和的或扩大的价值形式**。
3. **一般的价值形式**。
4. **货币形式** —— 商品价值的终极外化形式：用货币去衡量商品的价值。

**货币**：金银天然不是货币，但货币天然是金银。货币是在长期交换过程中形成的、固定充当一般等价物的**商品**。（货币只能是金银等贵金属）

**货币的五大职能**（其中，**价值尺度**和**流通手段**是最基本的职能）：

1. **价值尺度**：货币有衡量其他商品价值的功能。
   - **原因**：货币本身也是商品，也有价值。
   - 发挥货币的价值尺度职能时，人们可以通过**观念货币**（头脑中的货币／想象中的货币）去衡量某个商品的价值。例如看到一件价值$1000$元的衣服，你不需要真的掏出一千元钱放到这件衣服旁边比较一下，只需要在脑海中想一下$1000$元有多少，再和这件衣服比较一下就行了（现在钱太不扛花了呜呜呜）。
2. **流通手段**：货币可以充当商品交易的媒介。
   - 发挥货币的流通手段职能时，不能使用观念的货币，必须是**现实的货币**。比方说你买东西的时候老板收你$25$块钱，你说："老板你看我给你想一个$25$块钱，这东西我拿走了。"人家不给你打成渣都算人家没吃饱饭。
   - 货币在执行流通手段的时候可以**不足值**（会导致劣币驱逐良币）。为避免此现象，产生了**纸币**（纸币就是一张纸，它自身的价值可以忽略不计，因此纸币不能发挥价值尺度的作用。$20$张百元大钞看似能衡量一件价值$2000$元衣服的价值，是因为这$20$张纸背后站着的是真金白银，是国家信誉；而那$20$张百元大钞本身就是$20$张纸，什么都衡量不了），纸币是代替货币发挥流通手段的工具。
3. **贮藏手段**：货币退出流通被囤积。
4. **支付手段**：货币具有清偿，偿付，结算等功能。
   - 货币执行支付手段的时候必须是**现实的货币**。
   - **没有现货交易**。
5. **世界货币**：货币跨国际流通。

货币产生之后，整个商品世界分化成两极：一极是各种各样的具体商品，它们代表了不同的使用价值；另一极是货币，它们只代表商品的价值。由此，商品内在的使用价值和价值的矛盾就转化成商品和货币的外在矛盾。但是货币的出现并没有从根本上消除商品经济的矛盾，反而使矛盾加深。马克思把商品转化成货币称为"**惊险的跳跃**"，"这个跳跃如果不成功，摔坏的不一定是商品，但一定是商品的占有者"。（因为货币出现之后，人们生产的目的就从换取其他物品变成了赚取更多货币，而赚取货币本身是没有上限的，所以商品的生产者会不断扩大生产规模。跳跃不成功，就是说生产的商品卖不出去了，那么商品的所有者就会面临破产。）

### 四、价值有何规律

**价值规律**是商品经济的**基本经济规律**，它的内容和客观要求是：

- 商品的价值量由生产商品的社会必要劳动时间决定。
- 商品交换以价值量为基础，按照等价交换的原则进行。

**表现形式**：商品的价格会随着商品的价值自发变动。具体来说，商品价格会在商品价值的位置处来回上下波动，因为商品价格由**商品价值**决定，同时受多因素影响（供求、币值等）。

**价值规律的作用：**

- **积极作用：**
  - 自发调节生产资料和劳动力在社会各生产部门之间的分配比例。
  - 自发的刺激社会生产力的发展。
  - 自发地调节社会收入的分配。
- **消极作用：**
  - 导致社会资源浪费。
  - 导致收入两极分化。
  - 阻碍技术进步。

### 五、以私有制为基础的商品经济的基本矛盾

- **私人劳动**：指店铺的经营者看似很自由，想怎么干怎么干。
- **社会劳动**：指店铺的经营者为了盈利，需要把自己生产的商品卖到社会上赚钱。
- 私人劳动和社会劳动是**一个劳动的两个方面**，区别在于角度不同。
- **私人劳动和社会劳动的矛盾**构成私有制基础上商品经济的基本矛盾。私人劳动和社会劳动之间的矛盾在资本主义制度下进一步发展成**资本主义的基本矛盾**，即生产资料私人占有和生产社会化之间的矛盾。

### 六、劳动价值论的意义

马克思在**继承**英国古典政治经济学*劳动价值理论*的同时，**创立**了*劳动二重性理论*。

**深化对马克思劳动价值论的认识：**

- 深化对创造价值的劳动的认同，对生产性的劳动做出新的界定。
- 深化对科研人员、经营管理人员在社会生产和价值创造中所起的作用的认识。
- 深化对科技、知识、信息等要素在财富和价值创造中的作用的认识。
- 深化对**价值创造**（只有劳动能创造价值）与**价值分配关系**（劳动、信息以及其他资源均能参与价值分配）的认识。

## 资本主义经济制度

### 总纲

本部分围绕**剩余价值**这条主线展开：

1. **资本主义经济制度的产生** —— 资本主义生产关系与资本原始积累
2. **劳动力成为商品与货币转化为资本** —— 剩余价值生产的前提
3. **资本主义的运转过程** —— 剩余价值的生产、积累、流转与分配

### 一、资本主义经济制度的产生

> 本节内容要么不会考，要考也是考书上原话。

- **资本主义生产关系的产生**：途径有两个——一是从小商品经济中分化出来；二是从商人和高利贷者转化而来。
- **资本的原始积累**：途径——一是用暴力的手段剥夺农民的土地；二是用暴力手段掠夺货币财富。

### 二、劳动力成为商品与货币转化为资本

- **劳动力**：指人的劳动能力，是人的脑力和体力的总和。**劳动力的使用**就是劳动。

- **劳动力成为商品的两个必要条件：**
  1. 劳动者在法律上是**自由人**；
  2. 劳动者没有任何生产资料，没有别的商品可以出卖，**"自由"得一无所有**，没有任何实现自己的劳动力价值所必需的物质条件。

- **劳动力商品的两个因素：**
  - **价值**：由生产、发展、维持和延续劳动力所必需的生活必需品的价值决定。包括三个部分：
    1. 维持劳动者本人生存所必需的生活资料的价值；
    2. 维持劳动者家属生存所必需的生活资料的价值；
    3. 劳动者接受教育和训练所支出的费用。
    此外，劳动力的价值还受**历史和道德的因素**影响：即在不同国家、或同一国家的不同历史时期，劳动者所必需的生活资料的数量和构成是有区别的。
  - **使用价值**：劳动力商品在使用价值上有一个很突出的特点，就是它的**使用价值是价值的源泉**（你不能给我干活、给我挣钱，我为什么要雇你？）。它在消费的过程中能够创造一些新的价值，而且这个新的价值比劳动力本身的价值更大。当货币的所有者购买到劳动力这种特殊的商品后，就能够获得**剩余价值**，货币也就转化为**资本**。

### 三、资本主义的运转过程

**剩余价值**是资本主义运转的核心。下面按「如何生产 → 如何积累 → 如何流转 → 如何分配」四个问题依次展开。

#### （一）剩余价值是如何生产的

##### $1$. 资本主义生产过程的二重性

资本主义的生产过程具有二重性：

- 一方面是生产物质资料的过程；
- 另一方面是生产剩余价值的过程，即**价值增殖过程**。

资本主义生产过程是**劳动过程**和**增殖过程**的统一。（从劳动力的角度看，有一堆商品被生产出来了；从资本家的角度看，劳动力创造了大量的剩余价值。）

##### $2$. 资本主义劳动过程的两个特点

资本主义劳动过程是生产使用价值的过程。由于资本主义劳动过程的生产要素都被资本家占有，这就决定了：

1. 工人在资本家的监督下劳动；
2. 劳动成果和产品全部归资本家所有。

##### $3$. 价值增殖过程（剩余价值是如何被生产出来的）

**价值增殖过程是剩余价值的生产过程**，这是资本主义生产过程的主要方面。以「做包子」为例：

- 情形一：资本家花$40$元买生产资料、支付$20$元工资，工人干$4$小时把生产资料全部做成包子，卖包子得$60$元——其中$40$元补偿生产资料、$20$元发工资，资本家本质上**一分没赚**。
- 情形二：还是这个资本家，花$80$元买生产资料（量比原先多了一倍），工人就需要干$8$小时才能把这些生产资料都变成包子，但支付给工人的工资**还是$20$元**（马克思在《资本论》中分析：工人的价值不是由工作时长决定的，而是由保证这个工人活下去、能源源不断出卖劳动力的成本决定的）。包子都卖出去赚了$120$元——其中$80$元补偿生产资料、$20$元发工资，资本家净赚$20$元，这$20$元就是**剩余价值**，用$m$表示。

由此可以从三个角度分析：

- **从劳动角度分析：**
  - **具体劳动**：创造最终商品的**使用价值**（包子的使用价值是工人的具体劳动创造的）；同时转移生产资料的价值——工人通过具体劳动把生产资料的价值转移到包子的价值中去。
  - **抽象劳动**：创造新价值$40$元（$120 - 80$）——
    - $20$元被工人以工资的形式拿回家了；
    - $20$元成了$m$，即**剩余价值**，被资本家无偿占有。（所以"工人一天的劳动创造的新价值全部被资本家无偿占有"这种说法是错误的：新价值有一部分是工人的工资，剩下的才被资本家无偿占有。）
- **从资本角度分析：**资本家今天的总投资成本是$100$元——
  - $80$元购买生产资料$\rightarrow$全部转移进包子里（不会增殖，只会平行转移），这部分资本也叫**不变资本**，用$c$表示；
  - $20$元支付工资$\rightarrow$变成$40$元，发生了增殖，这部分资本也叫**可变资本**，用$v$表示。
  - 综上得到**剩余价值率**（剥削率），用$m^{\prime}$表示：$m^{\prime} = \frac{m}{v}$。本例中资本家的剩余价值率就是$\frac{20}{20} = 100\%$。
- **从时间角度分析：**工人一天工作$8$个小时创造了$40$元的新价值，如果劳动是均匀的，那么就是前$4$个小时创造$20$元、后$4$个小时也创造$20$元——
  - 前$4$个小时创造的$20$元以工资的形式被工人自己拿走了，此时工人在为自己创造自己的工资，没有剥削，所以这一部分也叫**必要劳动时间**；
  - 后$4$个小时创造的$20$元被资本家无偿占有，此时发生剥削，马克思把这段劳动时间称作**剩余劳动时间**。
  - 这两个时间段之间有一个分界点，超过这个分界点就发生了剥削。

##### $4$. 价值增殖过程的实质与资本的本质

所谓价值增殖过程，是超过劳动力价值的补偿这个**一定点**而延长了的价值形成过程。**资本**的本质不是物，而是一定的历史社会形态下的生产关系。

##### $5$. 提高剥削程度的两种基本方法

资本家提高对工人的剥削程度的方法是多种多样的，最基本的方法有两种：

1. **绝对剩余价值的生产**：指在必要劳动时间不变的情况下，由于延长工作日的长度或提高劳动强度而生产的剩余价值。
2. **相对剩余价值的生产**：指在工作日长度不变的条件下，通过缩短必要劳动时间而相对延长剩余劳动时间所生产的剩余价值。

（回到做$8$个小时包子的例子：资本家此时已经榨取了$20$元的剩余价值，还想榨取更多，就有两种手段——第一，加班，只要人干不死就继续干，通过这种方式榨取到的剩余价值就叫**绝对剩余价值**；第二，假设现在这个资本主义国家已经走向了文明化，国家要求必须只能工作$8$小时、$8$小时到了必须放人回家，这个时候资本家还想榨取更多价值还有一种办法：提高效率、科技进步、提高劳动生产率。假设科技进步使生产效率提高了一倍，原来工人赚取到自己的劳动工资需要$4$个小时，现在只需要$2$个小时，那后面$6$个小时就都变成了剩余劳动时间，通过这种方式赚取到的剩余价值就叫**相对剩余价值**。）

##### $6$. 超额剩余价值

**超额剩余价值**：**（个别）企业**提高了自己的劳动生产率，使得它生产的商品的个别价值低于社会价值的差额（即单个企业提高生产率多赚的这些就叫超额剩余价值）。在资本主义商品的生产条件下，每个资本家总是力图不断改进技术、改善经营管理、提高劳动生产率，使其生产的商品的个别价值低于社会价值，从而获得超额剩余价值。（这里有个因果关系：超额剩余价值不能长期存在，因为其他企业发现你生产率提高后会想办法学习你的技术，最终导致全社会的生产率都提高，这也就最终导致了整个资本家阶级获得的**相对剩余价值**的提高。）

##### $7$. 生产自动化条件下剩余价值的源泉

（生产自动化就是指无人车间、自动化流水作业之类的。那么这种情况下马克思的理论还正确吗？马克思的理论还是正确的，理由如下：）

1. 不存在绝对的自动化，不存在绝对的无人车间，这些东西也是需要技术人员去维护的；
2. 采用这些自动化生产工具，无非是转移了生产自动化器具的工人的劳动价值到你这里来而已。

资本主义条件下的生产自动化是资本家获取高额剩余价值的手段，而**雇佣工人的劳动仍是获得这种剩余价值的唯一源泉**。

#### （二）剩余价值是如何积累的

##### $1$. 资本积累与两种再生产

- **资本积累**：把剩余价值转化为资本，或者说剩余价值资本化。（还是上面那个做$8$小时包子的资本家：今天他得到了$20$元剩余价值，如果这$20$元全部用于消费，那么明天他的本金还是$100$元，明天的生产过程就是今天的简单重复；但资本家通常不会把剩余价值全部消费掉，而是把其中一部分追加到本金中——例如留下$10$元，那么明天他的本金就是$110$元。这个过程就是**资本积累**。）
- **资本主义简单再生产**：资本家在获得剩余价值后，如果将其全部用于个人消费，则生产就在原有规模的基础上重复进行。（现实的资本家肯定不会这么干）
- **资本主义扩大再生产**：资本家将获得的剩余价值的一部分转化为资本，使生产在扩大的规模上重复进行。资本主义再生产的特点就是**资本主义扩大再生产**，而**资本积累**是资本主义扩大再生产的**源泉**。

##### $2$. 资本积累的本质与源泉

- **资本积累的本质**：资本家不断利用无偿占有的、工人创造的剩余价值来扩大自己的资本规模，从而进一步扩大和加强对工人的剥削和统治。
- **资本积累的源泉**：资本积累的源泉是**剩余价值**。（糖葫芦考点：扩大再生产的源泉是资本积累，资本积累的源泉是剩余价值。）

##### $3$. 影响资本积累规模的因素

资本积累规模的大小，与下列因素成**正比**：

- **资本家对工人的剥削程度**；
- **劳动生产率的高低**；
- **所用资本和所费资本之间的差额**（所用资本：指资本家的投资额；所费资本：指的是此轮生产中消耗的资本）；
- **资本家预付资本的大小**。

##### $4$. 资本积累的后果

资本积累和生产规模的扩大，必然加剧社会的**两极分化**——一极是财富越来越集中在少数人手中，另一极是多数人只拥有社会财富的较小部分。所以**资本积累不但是社会财富占有两极分化的重要原因，而且是资本主义社会失业现象产生的根源。**

##### $5$. 资本有机构成

- **资本的技术构成**：由生产的技术水平决定的生产资料和劳动力之间的比例，叫做**资本的技术构成**。（回到卖包子的例子：资本家花$80$块买了$4$斤面（生产资料）、花$20$块买了$1$个技术工人（劳动力），这里「$4$斤面 : $1$个技术工人」就是技术构成。）
- **资本的价值构成**：从价值形式上看，资本可以分为**不变资本**和**可变资本**，这两部分资本价值之间的比例就是**资本的价值构成**。（同样这个例子：买面的$80$元就是**不变资本（$c$）**，买技术工人的$20$元就是**可变资本（$v$）**，这里「$80$ : $20$」就是价值构成。）
- （技术构成和价值构成在内在其实是相通的，只不过一个形式上是物比物、一个是钱比钱而已。）
- **资本的有机构成**：这种由资本的技术构成决定、并反映技术构成变化的资本价值构成，叫做资本的有机构成，通常用$c : v$表示。（说人话：因为技术构成发生变化，导致价值构成也发生了变化，这个时候的价值构成就叫有机构成。）

口诀：

$$
技术变，价值变，有机就变
\\\\
技术不变，价值变，有机就不变
$$

##### $6$. 相对过剩人口

在资本主义的生产过程中，**资本的有机构成呈现不断提高的趋势**，这是由资本无限追逐剩余价值的本性决定的。资本家通过资本积累和资本集中扩大生产规模，使资本有机构成不断提高。资本有机构成提高，导致可变资本相对减少，资本对劳动力的需求日益相对减少，其结果就不可避免地造成大批工人失业，形成**相对过剩人口**。（这就是马克思的失业理论。）

##### $7$. 资本积累的历史趋势

资本积累的历史趋势是**资本主义制度的必然灭亡和社会主义制度的必然胜利。**（资本积累$\rightarrow$资本的有机构成提高$\rightarrow$导致失业$\rightarrow$加大两极分化$\rightarrow$资本主义必将灭亡）

#### （三）剩余价值是如何流转的

##### $1$. 资本循环

- **资本循环**：资本从一种形式出发，经过一系列形式的变化，又回到原来出发点的运动。
- 产业资本循环过程中要经历三个不同的阶段，与此相联系的是**资本依次执行三种不同的职能**：
  1. **采购阶段** —— 产业资本执行的是**货币资本**；
  2. **生产阶段** —— 产业资本执行的是**生产资本**；
  3. **售卖阶段** —— 产业资本执行的是**商品资本**。
- （具体来说，还是卖包子的资本家：他拿钱购买生产资料和工人，这个钱就是**货币资本**；花钱买回来的生产资料和工人就是**生产资本**；工人把生产资料做成了包子往外卖，这个包子就是**商品资本**；包子卖完了赚到的钱，又变成了资本家的**货币资本**。）
- **产业资本运动的两个基本前提条件：**
  1. **三种职能形式在空间上并存**。（企业里有采购部、生产车间和销售部，这三个部门是同时工作的，没有谁等谁这个说法。）
  2. **三种职能形式在时间上继起**。（企业的采购部、生产车间和销售部一环咬着一环、丝丝相扣；其中任何一个环节断了，就是资金链断裂。）

##### $2$. 资本周转

- **资本周转**：资本是在运动中增殖的，资本周而复始、不断往复的循环，就是资本的周转。如果每次资本周转带来的剩余价值一定，则资本周转越快，在一定时期内带来的剩余价值就越多。（所以周转越快的行业，越受资本青睐。）
- **影响资本周转的两个关键因素：**
  1. **资本周转的时间**——周转时间越长，赚的就越慢；
  2. **生产资本中固定资本和流动资本的构成**。
     - **固定资本**：分多次转移到最终商品中的资本。（例如和面用的盆：今天用完盆和面，明天还能接着用。）
     - **流动资本**：一次转移到最终商品中的资本。（例如做包子的面：今天用完之后明天就要重新买。）

##### $3$. 马克思对资本的三次划分

| 划分 | 划分依据 | 划分结果 |
| --- | --- | --- |
| 第一次划分 | 资本在剩余价值生产中的作用不同 | **不变资本**（$c$，购买生产资料，只转移价值、不增殖）和**可变资本**（$v$，购买劳动力，能增殖） |
| 第二次划分 | 产业资本在循环过程中执行的职能不同 | **货币资本**、**生产资本**和**商品资本** |
| 第三次划分 | 资本价值的周转方式（转移方式）不同 | **固定资本**（价值分多次转移）和**流动资本**（价值一次转移） |

例如，在奶牛场里的一些资本划分：

| 划分 | 奶牛 | 种牛 | 肉牛 | 劳动力 |
| --- | --- | --- | --- | --- |
| 不变资本／可变资本 | 不变资本 | 不变资本 | 不变资本 | 可变资本 |
| 货币资本／生产资本／商品资本 | 生产资本 | 生产资本 | 商品资本 | 生产资本 |
| 固定资本／流动资本 | 固定资本 | 固定资本 | 流动资本 | 流动资本（劳动者干了一天的活，劳动力耗光了） |

##### $4$. 社会再生产

- **社会再生产的核心问题**：社会生产是连续不断地进行的，这种连续不断重复的生产就是再生产。社会再生产的**核心**问题是**社会总产品的实现问题，即社会总产品的价值补偿和实物补偿问题**。（价值补偿：即商品卖出去、钱收回来；实物补偿：即原材料源源不断地进来。只有这两种补偿源源不断地得到补充，整个社会才能一直运转下去。）
- **马克思分析社会再生产问题的两个理论前提：**
  1. **社会总产品在价值形态上**又叫社会总价值，包括生产资料（$c$）、工人价值（$v$）、剩余劳动时间里创造的价值（$m$），即$c+v+m$；
  2. **社会总产品在物质形态上**划分为两大类，即第$I$部类和第$\mathrm{II}$部类——第$I$部类由生产生产资料的部门组成；第$\mathrm{II}$部类由生产消费资料（生活资料）的部门组成。
- **社会再生产顺利进行的条件**：生产资料的生产既要满足两大部类对所耗费掉的生产资料的补偿，也要保证两大部类扩大生产规模后对追加生产资料的需求；消费资料的生产要满足两大部类劳动者的个人消费和社会消费，也要满足扩大生产规模后对追加消费资料的需求。

**两大部类的失衡与经济危机：**

在资本主义发展相当长的时间里，由生产资料的私有制和雇佣劳动制度所决定，两大部类的生产都是在价值规律和剩余价值规律的作用下自发进行的，具有严重的盲目性。这就导致了两大部类的生产在规模上和结构上经常处于失衡状态，最严重的就是引发**经济危机**。经济危机实际上是**资本主义条件下以强制的方式解决社会再生产的实现问题的途径**。

**用公式来理解：**把全社会的资本家分成两大类——

1. **第$I$类：生产生产资料的资本家**（例如生产挖掘机的资本家，这种资本家生产的产品是卖给别的企业做生产资料的）；
2. **第$\mathrm{II}$类：生产生活资料的资本家**（例如生产衣服等的资本家，老百姓会直接到他这买东西带回家生活使用）。

整个社会所有产品的总价值是$c + v + m$，即所有产品的生产资料的价值 + 工人的工资 + 剩余价值。

我们把第一类资本家生产的产品放到一起，就是

$$
I_C + I_V + I_M
$$

再把第二类资本家生产的产品放到一起，就是

$$
II_C + II_V + II_M
$$

- 第一个公式里的$I_C$是第一类资本家购买生产资料要花的钱，但是因为第一类资本家自己就是生产生产资料的，所以第一类资本家购买生产资料就找本部门去买，$I_C$这部分钱**部门内部自动消化掉**了。
- 第一个公式里的$I_V$是生产生产资料的工人的工资；在不考虑资本主义扩大生产的条件下，$I_M$是资本家吃喝拉撒的钱。这个条件下，$I_V + I_M$是第一类工人和资本家生活要用到的钱——这部分的钱找谁要呢？找第二类的人要，因此这部分钱就牵扯到**跨部门交换**。
- 同理分析，第二部类的$II_C$是买生产资料的钱，找第一部类的人要，发生跨部门交换；第二部类的$II_V + II_M$是第二部类的资本家和工人生活用的钱，**部门内部消化**。

因此，整个社会平衡发展的条件就是：

$$
II_C = I_V + I_M
$$

但是资本主义社会中由于缺乏国家对经济的干预和规划，所以这个平衡往往很难达到；当这种失衡走到最极端严重的情况下，就会产生**经济危机**（这个等式的两边之中任何一边走到一个极端、多出来太多太多了，而另一边没有足够的东西和它交换）。

#### （四）剩余价值是如何分配的

剩余价值在资本主义各剥削集团之间进行分配，具体表现为工资、利润（平均利润）以及借贷资本利息等具体形式。

##### $1$. 资本主义工资

- **本质**：在资本主义制度下，工人的工资是**劳动力的价值或价格**，这是资本主义工资的本质。
- **表现形式**：由于资本家在购买工人劳动力时是以货币为单位进行支付的，因此工资就**表现为**（即看起来像）**"劳动的价格"或工人全部劳动的报酬**——这就模糊了工人必要劳动和剩余劳动的界限，**掩盖了资本主义的剥削关系**。

##### $2$. 利润与平均利润

- **利润的本质**：**剩余价值**是利润的本质，利润是剩余价值的**转化形式**。当剩余价值转化为利润时，剩余价值和可变资本的关系就被掩盖了。（剩余价值和利润仅是看待角度不同：一个为了揭露剥削，另一个为了掩盖剥削。）
- **平均利润**：资本主义生产是为了获得剥削，因此不同部门之间如果利润率不同，资本家之间就会展开激烈的竞争，使资本从利润率低的部门流向利润率高的部门，从而导致利润率趋于平均化。不同部门的资本家按照**等量资本获得等量利润**的原则来瓜分剩余价值；按照平均利润率来计算和获得的利润，就叫**平均利润**。
- **生产价格**：随着利润转化为平均利润，商品价值就转化为**生产价格**（即商品的成本价格 + 平均利润）。
- 例（回到做$8$小时包子的资本家）：假设社会平均利润率是$20\%$，他的生产成本是$100$元（$80$元买生产资料、$20$元买工人），那么他的平均利润就是$100 \times 20\% = 20$元，因此生产价格$= 100 + 20 = 120$元。

##### $3$. 价值规律表现形式的变化

在价值转化为生产价格的条件下，价值规律作用的形式发生了变化：商品不再以价值、而是以**生产价格**为基础进行交换，市场价格的变动不再以价值为中心，而是以**生产价格**为中心。

（在简单商品经济时期，价格围绕着**价值**上下波动；到了资本主义经济时期，又分成两个阶段——

- **自由竞争资本主义经济时期**：价值规律没变，但价值规律的表现形式发生变化——商品的价格不再围绕价值波动，而是围绕着**生产价格**波动，即围绕着「成本 + 平均利润」波动。所以说"亏本卖"，不是说商家$100$块进的货他$90$块卖你，而是说$100$块进的货，在平均利润率$20\%$的条件下，他正常卖$120$能赚到$20$块，但是他$110$卖你。
- **垄断资本主义经济形式**（第六章详细讲）：反正只要还有商品、只要还有市场，价值规律就永远不会变，变的只是价值规律的表现形式。）

在利润率平均化的作用下，各路资本家都获得自己的利润。即利润平均化规律反映了：在瓜分剩余价值上，资本家之间存在竞争和矛盾，但在加强对工人阶级的剥削以榨取更大量的剩余价值这一点上，资本家之间又有着共同的阶级利益。

##### $4$. 借贷资本

有一种资本是**借贷资本**：借贷资本能不能获得平均利润呢？借贷资本获得的利润$\lt$平均利润。

### 四、马克思剩余价值理论的意义

剩余价值理论揭露了资本主义剥削的本质，阐明了资产阶级和无产阶级之间阶级斗争的经济根源，是马克思主义经济学说的核心内容和基石。

### 五、资本主义的基本矛盾和经济危机

- **资本主义的基本矛盾**：生产资料资本主义**私人占有**和生产社会化之间的矛盾。

- **经济危机的本质特征：生产相对过剩**。（相对过剩：指相对于劳动人民有支付能力的需求来说，社会生产的商品显得过剩，而不是与劳动人民的实际需求相比的绝对过剩。）

- **经济危机爆发的根本原因**：经济危机的抽象的一般的可能性是由货币作为流通手段和支付手段引起的，但这仅仅是危机在形式上的可能性；资本主义经济危机爆发的根本原因是**资本主义的基本矛盾**。这一基本矛盾具体表现在两个方面：
  1. 生产无限扩大的趋势，和劳动人民有支付能力的需求相对缩小的矛盾；
  2. 单个企业内部生产的有组织性，和整个社会生产的无政府状态之间的矛盾。

- **经济危机的周期性**：经济危机呈周期性爆发，一般包括四个阶段——**危机**（本质阶段）、**萧条**、**复苏**、**高涨**。

## 资本主义上层建筑

### 一、资本主义的国家、民主制度及其本质

- **资本主义国家的职能**：是**服务于资本主义制度和资产阶级利益**，包括对内和对外两个基本方面：
  1. **对内**：实行政治统治和社会管理；
  2. **对外**：实行国际交往和维护国家安全利益。

- **资本主义的民主制度**：是**与资本主义生产方式相适应**而发展起来的，有"主权在民"、"天赋人权"、"分权制衡"、"社会契约论"和"自由、平等、博爱"等政治思想。

- **资本主义法律制度的基本原则**：私有制原则、主权在民原则、分权制原则和人权原则。

- **国家政权的组织形式**：采取分权制下的组织形式（即"三权分立"）——立法权、行政权、司法权分别由三个权利主体独立行使，形成各主体之间的"制衡"。

- **资本主义国家的选举制度**：从形式上看，竞选制度是公民参与国家事务的重要形式；从实际上看，选举制是协调统治阶级内部利益关系和矛盾的重要措施。

- **政党**：当代资本主义国家基本上实行政党制度，大致有**两党制**和**多党制**等形式。

- **资本主义政治制度的评价**：我们承认资本主义政治制度有一定进步作用，比当年的封建制度是更民主进步的；但本质上仍然是资产阶级进行政治统治和社会管理的手段和方式，是为资产阶级专政服务的，有其局限性，体现在：
  1. 资本主义的民主是金钱操纵下的民主，实际上是精英统治的民主；
  2. 法律名义上的平等掩盖着事实上的不平等；
  3. 资本主义国家的政党制度是一种维护资产阶级统治的政治制度，是实现其内部平衡的政治机制；
  4. 政党恶斗相互掣肘，决策效率低下，激化社会矛盾。

### 二、如何评价资本主义意识形态

资本主义意识形态作为资产阶级经济和政治的集中反映，是为巩固资产阶级的政治统治、维护资本主义政治制度、为资产阶级的阶级剥削和阶级压迫服务的。


第五章讲资本主义的本质和规律，第六章接着讲它在垄断阶段的新变化，以及经济全球化和当代资本主义的新特征。

# 第六章 资本主义的发展及其趋势

## 垄断资本主义的形成与发展


### 一、资本主义从自由竞争到垄断

#### （一）垄断的形成

资本主义的发展经历了**自由竞争资本主义**和**垄断资本主义**两个阶段；垄断资本主义的发展又分为**私人垄断资本主义**、**国家垄断资本主义**和**国际垄断资本主义**。

- **垄断形成的方式：**
  - **生产集中**：指生产资料、劳动力和商品的生产日益集中于少数大企业的过程。
  - **资本集中**：指大资本吞并小资本，或由许多小资本合并而成大资本的过程。

- **垄断的概念**：垄断是指少数资本主义大企业为了获得高额利润，通过相互协议或联合，对一个或几个部门商品的生产、销售和价格进行操纵和控制。

- **垄断形成的原因：**
  1. 为了获得高额利润；
  2. 为了避免两败俱伤；
  3. 为了形成对竞争的限制。

- **垄断的形式**：最简单、初级的垄断形式叫**短期价格协定**。尽管垄断组织的形式多种多样，但它们本质上是一样的：即通过联合实现独占或瓜分商品生产和销售市场，操纵垄断价格，以攫取**高额垄断利润**。

#### （二）垄断条件下的竞争

**垄断资本主义阶段仍然存在竞争的原因：**

1. 垄断并没有消除产生竞争的*经济条件*（即私有制）；
2. 垄断必须通过竞争来维持；
3. 社会生产是复杂多样的，任何垄断组织都不可能把包罗万象的社会生产全部包下来。（住在黄崖关原始森林那个七进七出四合院、早上四点起来煮$400$个茶鸡蛋、垄断天津城内大大小小生意的于谦的岳父除外。）

**垄断条件下的竞争和自由竞争相比的新特点：**

- **竞争目的上**：自由竞争是为了获得更多的平均利润或超额利润，垄断条件下的竞争是为了获得高额的垄断利润。
- **竞争手段上**：自由竞争主要运用经济手段（比如打价格战），垄断条件下的竞争不仅采取经济手段，还采取非经济手段（比如让政府帮助出个文件，这个文件说这个生意只能我来做，你们都别做了）。
- **竞争范围上**：自由竞争主要还是在经济领域，而且主要在国内市场；垄断条件下的竞争规模扩大，且逐步扩展到国外。

#### （三）金融资本与金融寡头

- **金融资本形成的主要途径**：**金融联系**、**资本参与**、**人事参与**等。

- **金融寡头如何操控社会：**
  - **经济方面**：主要通过"参与制"（即金融寡头通过掌握一定数量的股票来控制企业）；
  - **政治方面**：主要通过同政府的**个人联合**（即亲自担任或委派代理人担任政府要职）；
  - **其他方面**：建立政策咨询机构等方式对政府的政策施加影响；掌握新闻出版、广播电视、科学教育、文化体育等上层建筑的各个领域，左右国家内政外交及社会生活。

#### （四）垄断利润与垄断价格

- **垄断利润**：垄断资本家获得的高额利润。

- **垄断利润的来源**：**归根到底来自于无产阶级和其他劳动人民创造的剩余价值**。具体来说有以下几个方面：
  1. 对本国人民进行剥削；
  2. 通过垄断高价和垄断低价来控制市场，使它能够获得一些非垄断企业的利润（例如，你是一个养鸡场老板，你养的鸡最后要卖到麦当劳等地方，因为麦当劳等在卖炸鸡的领域里是垄断企业，有庞大且稳定的需求；你为了留住这个客户就会去低价售卖，把一部分本该属于你自己的利润让出去）；
  3. 对其他国家的劳动人民的剥削和掠夺；
  4. 通过资本主义国家政权进行有利于垄断资本的再分配，从而将劳动人民创造的国民收入的一部分变成垄断资本的收入（即制定一些政策，把曾经老百姓交的税用作企业的补贴）。

- **垄断利润的实现**：通过**垄断价格**实现。垄断价格的计算公式为：

$$
\begin{aligned}
\text{垄断价格} &= \text{成本价格} + \text{平均利润} + \text{垄断利润} \\
&= \text{生产价格} + \text{垄断利润}
\end{aligned}
$$

- **垄断价格的两种形式：**
  - **垄断高价**：（回到养鸡场的案例，因为麦当劳的垄断地位，它可以把鸡翅卖得很贵，这个就是垄断高价）
  - **垄断低价**：（回到养鸡场的案例，麦当劳收购原材料的时候会不断压价，以一个很低的价格获得原材料）

- 垄断价格的产生并**不**否定价值规律，它是**价值规律在垄断资本主义阶段的具体体现**。（在简单商品经济时期，价格围绕着价值上下波动；在自由竞争资本主义时期，价格围绕着生产价格上下波动；在垄断资本主义时期，价格围绕着垄断价格上下波动。）

### 二、垄断资本主义的发展

#### （一）国家垄断资本主义

- **国家垄断资本主义产生的原因：**
  1. 社会生产力的发展（根本原因）；
  2. 经济波动和经济危机的深化，需要国家进行干预；
  3. 为了缓和社会矛盾、协调利益关系，需要国家来插手协调。

- **国家垄断资本主义的形式：**
  1. 国家所有并直接经营的企业（央国企）；
  2. 国家与私人共有、合营企业（经营得好的私人企业国家会入股）；
  3. 国家通过多种形式参与私人垄断资本的再生产过程；
  4. **宏观调节**：通过财政或货币等**手段**对社会经济进行调节，目标是实现**经济快速增长、充分就业、物价稳定和国际收支平衡**；
  5. **微观规制**：通过法律的**手段**，目标是**规范市场秩序、限制垄断、保护竞争、维护社会公众的合法权益**。

- **微观规制**有三种类型：一是反托拉斯法（也叫反垄断法），二是公共事业规制，三是经济规制。

- （宏观调节不针对某个企业，微观规制是针对某个企业的）

- **对国家垄断资本的评价**：有一定的积极作用，但是国家垄断资本主义的出现没有根本改变垄断资本主义的性质。国家垄断资本主义的出现是资本主义经济制度内的经济关系调整，并没有消除资本主义的基本矛盾。实质上是私人垄断资本利用国家机器为自己服务，是私人垄断资本为了维护垄断统治和高额利润而与国家相结合的一种形式。

#### （二）金融垄断资本的发展

- **金融垄断资本形成的条件**：**金融自由化**（即西方国家允许自由把货币换成其他国家的货币）和**金融创新**（金融产品不断衍生、不断迭代）是金融垄断资本得以形成和壮大的**重要制度条件**。

- **金融资本扩张的后果：**
  1. 金融业在国民经济中的地位大幅上升；
  2. 实体经济利润下降，他们不得不把利润的一部分投向金融领域，导致金融资本膨胀，制造业就业人数减少，以金融为核心的服务业就业人数增加，虚拟经济越来越脱离实体经济。

#### （三）垄断资本向世界范围的扩展

- **扩展的动因：**
  1. 将国内过剩资本输出；
  2. 将部分*非要害*的技术转移到国外，以获得在别国的垄断优势；
  3. 争夺商品销售市场；
  4. 确保原材料和能源的可靠来源。

- **扩张的形式：**
  1. **借贷资本输出**；
  2. **生产资本输出**；
  3. **商品资本输出**。

- **扩展的后果：**
  - **对资本输出国来说**：带来巨大的利润，扩大了商品输出，大大改善了国际收支状况，形成了对发展中国家经济命脉的控制（只好不坏）；
  - **对资本输入国来说**：好处是吸收了外部的资金，引进了先进的技术，培训了技术和管理人员，促进了经济发展，增加了就业机会，扩大了外贸等；坏处是造成环境污染、能源消耗，冲击了本国的民族工业，增加债务，对国际资本依赖加重（有好有坏）。

- **国际垄断同盟**：垄断资本国际化条件下形成的垄断组织。其发展分成两个阶段——早期叫**国际卡特尔**，今天叫**以国家垄断资本主义的国际联盟**。

- 国际垄断除了形成同盟，还形成各种国际经济协调体系来加强国际协调，主要有**国际货币基金组织**、**世界银行**和**世界贸易组织**（对，就是$\mathrm{WTO}$）（这三个是同盟之间的协调机构）。

- **对走向国际的国家垄断资本的评价**：一定程度上来说，促进了经济全球化的发展（优点）；从根本上说，它们都是为了维护资产阶级的利益，是为资产阶级攫取高利润服务的（缺点）。

### 三、经济全球化及其影响

#### （一）经济全球化的表现与动因

- **经济全球化的表现：**
  1. **生产全球化**：工厂开在全世界；
  2. **贸易全球化**：商品卖到全世界；
  3. **金融全球化**：钱从全世界赚。

- **导致经济全球化的因素：**
  1. 科技的进步和生产力的发展（根本原因）；
  2. 跨国公司的发展；
  3. 各国经济体制的变革和国际经济组织的发展。

#### （二）经济全球化的影响

- **对发展中国家的积极因素：**
  1. 给我们提供了先进的技术和经验；
  2. 创造了很多就业机会；
  3. 推动了国际贸易的发展；
  4. 促进了我国本国企业的发展。

- **对发展中国家的消极因素：**
  1. 加剧经济不平衡；
  2. 加剧资源短缺和环境污染；
  3. 增加了经济风险。

## 正确认识当代资本主义的新变化

### 一、第二次世界大战后资本主义的新变化

- **生产资料私有制的变化：**
  1. 私人资本所有制占主导地位；
  2. 私人股份资本所有制、国家资本所有制、法人资本所有制崛起并占主导地位。

- **劳资关系和分配关系的变化**：出现的新制度有**职工参与决策**、**终身雇佣**、**职工持股**。

- **社会阶层和阶级结构的变化：**
  1. 资本家的地位发生变化，他们一般不再直接经营和管理企业，而是靠利息收入为生；
  2. 高级职业经理人（$\mathrm{CEO}$）成为大公司及其活动的实际控制者；
  3. 知识型和服务型的劳动者的数量不断增加，劳动方式获得了很大变化。

- **经济调节机制和经济危机形态的变化**：周期性危机（资本主义的经济危机呈现出周期性的过程：危机$\rightarrow$萧条$\rightarrow$复苏$\rightarrow$高涨）和结构性危机（某个行业危机、别的行业不危机，或者某个地区危机、其他地方不危机）交织在一起，金融危机频发，全球经济遭受打击。（周期性危机仍然是其最基本特征。）

- **政治制度的变化**：首先，出现多元化的趋势；其次，法制建设得到重视和加强；最后，改良主义政党在政治舞台上的影响逐渐扩大。

### 二、第二次世界大战后资本主义新变化的原因和实质

- **第二次世界大战后资本主义发生新变化的原因：**
  1. 科学技术革命和生产力的发展（根本原因）；
  2. 工人阶级争取自身权利和利益的斗争；
  3. 社会主义制度优越性的影响；
  4. 改良主义政党对资本主义制度的改革。

- **第二次世界大战后资本主义发生新变化的实质：**
  1. 这些变化从根本上来说只是人类社会发展一般规律和资本主义经济规律作用的结果；
  2. 这些变化说到底还是**资本主义制度框架内**的变化，并不意味着资本主义生产关系的根本性质发生了变化。

### 三、当代资本主义变化的新特征

- **第一，科技创新加速资本主义生产方式变化。**

- **第二，国际金融垄断资本主义的影响日益显现**——这是当代资本主义**最突出**、**最鲜明**、**最主要**的特征（所以如果考当代的变化，单选题肯定选这个）。

- **第三，社会阶级层级结构日益复杂化**：由于新一轮的信息技术体系在世界范围内掀起了新一轮的**制造业退潮**和**服务业涨潮**，传统技能逐渐被智能化、自动化取代，从事信息、金融等中介服务业的"知识工人"数量和增长速度均超过"非知识工人"，工人阶级内部因技能和收入等方面的差异逐渐分化。

- **第四，发达资本主义国家凭借经济、科技、文化传播等超级优势，在世界范围内推行霸权**，具体表现为：
  1. 对发展中国家进行盘剥和压榨，获得绝对统治地位；
  2. 利用强大的文化产业和传媒垄断权，直接严重威胁民族国家的文化认同和文化主权，撕裂价值观的共同基础（比如对日本的"去雄化"，把昭和男儿变成平成废柴了）；
  3. 利用"信息鸿沟"和"数字鸿沟"，构建"信息帝国主义"和"数字帝国主义"；
  4. 对他国进行政治、经济、科技的全方位制裁，破坏全球的和平稳定。

政治经济学揭示了资本主义的内在矛盾。科学社会主义接着回答：社会主义为什么必然代替资本主义，共产主义社会是什么样。

# 第七章 社会主义的发展及其规律

## 总纲

科学社会主义是马克思主义的**目的和归宿**。前面哲学讲世界观和方法论，政经讲资本主义的运行规律，这一部分主要回答两个问题：

1. **社会主义从哪里来、怎么发展**——五百年的历史进程、苏联的实践与社会主义建设的曲折发展。
2. **共产主义是什么样**——预见未来社会的方法论与共产主义社会的基本特征。


## 社会主义五百年的历史进程

### 一、社会主义从空想到科学

#### （一）空想社会主义的三个阶段

| 阶段 | 代表人物及代表作 | 主要特点 |
| --- | --- | --- |
| **早期空想社会主义**（$16$—$17$世纪） | 莫尔《乌托邦》、康帕内拉《太阳城》 | 用文学游记的形式描绘理想社会，对未来的社会制度作了空想描写 |
| **空想社会主义的发展**（$18$世纪） | 摩莱里《自然法典》、马布利《论法制或法律的原则》 | 开始从理论上探讨消灭私有制、建立理想社会的问题 |
| **空想社会主义的高峰**（$19$世纪初） | 圣西门、傅立叶、欧文 | 三大空想社会主义者，尖锐批判资本主义制度，对未来社会提出了许多积极主张和天才猜测 |

**三大空想社会主义者的具体设想**：

- **圣西门**：提出“实业制度”，主张由实业家和学者掌握社会权力，按才能和贡献分配。
- **傅立叶**：提出“和谐制度”，设想以“法郎吉”为基本单位的协作社。
- **欧文**：进行“新拉纳克”工厂改革和“新和谐公社”试验，主张消灭私有制、建立公有制。

以这三个人为代表的空想社会主义是**科学社会主义的直接思想来源**。

**空想社会主义的局限**：

1. 只看到了资本主义必然灭亡的命运，却**未能揭示资本主义必然灭亡的经济根源**（即资本主义的基本矛盾）。
2. 要求埋葬资本主义，却**看不到埋葬资本主义的社会力量**（即工人阶级）。
3. 憧憬取代资本主义的理想社会，却**找不到通往理想社会的现实道路**（即无产阶级革命）。

#### （二）科学社会主义的创立

**马克思在理论上的两大历史贡献**：

| 理论基石 | 揭示的问题 | 在科学社会主义中的作用 |
| --- | --- | --- |
| **唯物史观** | 人类社会发展的一般规律 | 说明了社会主义代替资本主义的历史必然性 |
| **剩余价值学说** | 资本主义剥削的秘密 | 找到了埋葬资本主义、实现社会主义的社会力量 |

**补充**：马克思在哲学史上的两大历史贡献是**辩证唯物主义**和**历史唯物主义（唯物史观）**。

- **$1848$年《共产党宣言》发表**，标志着科学社会主义的诞生，也标志着马克思主义的诞生。

### 二、社会主义从理想到现实、从一国到多国的发展

#### （一）巴黎公社

**马克思、恩格斯总结的巴黎公社经验**：

1. 无产阶级革命取得成功并保持胜利果实的首要条件是要有**革命的武装**。（马克思、恩格斯主张暴力革命）
2. 必须打碎旧的国家机器，建立无产阶级的新型国家。
3. 无产阶级政权是为人民服务的政权。
4. 必须建立无产阶级政党，发挥党的政治指导作用。

**补充：世界各国无产阶级政党的关系原则**：

1. 要联合起来。
2. 一律平等。

#### （二）十月革命

**十月革命的意义**：

1. 建立了世界上第一个社会主义国家。
2. 沉重地打击了帝国主义的统治。
3. 激励了殖民地、半殖民地的民族民主革命。
4. 促进了马克思列宁主义的传播，推动了无产阶级政党的建立。

#### （三）社会主义在苏联的实践

##### $1$. 战时共产主义时期

列宁领导的苏维埃政权实施了以**余粮收集制**和**取消商品货币关系**为特征的战时共产主义政策，在经济上采取了一系列特殊而带有强制性的非常措施。

##### $2$. 新经济政策时期

以**发展商品经济**为主要特征的新经济政策，主要内容有：

- 用粮食税制取代余粮收集制；
- 允许私人自由贸易；
- 恢复商品货币关系；
- 允许私人小工业发展；
- 采取一些国家资本主义的措施来发展生产。

新经济政策标志着列宁正在探索一条符合俄国情况的建设社会主义的道路。

**实行新经济政策期间，列宁提出的精辟论述**：

1. 把建设社会主义作为一个长期探索、不断实践的过程。
2. 要大力发展生产力，提高劳动生产率。
3. 允许多种经济成分并存。
4. 利用资本主义建设社会主义。

#### （四）苏联模式

**苏联模式的基本特征**：

##### $1$. 经济方面

- **经济发展战略**：以高速度发展经济为首要任务，以重工业为发展重点。
- **经济体制**：单一的生产资料公有制，排斥市场机制，完全采用行政手段，形成过度集中的指令性计划经济模式。

##### $2$. 政治方面

过度集权的党和国家领导体制，自上而下的干部任命制，软弱低效的监督机制。

### 三、社会主义建设的曲折发展和不断完善

#### （一）社会主义建设具有艰巨性和长期性

**原因**：

1. 生产力状况的制约（根本原因）。
2. 经济基础和上层建筑发展状况的制约。
3. 国际环境的严峻挑战。
4. 马克思主义执政党对社会主义建设规律的认识也有一个过程。

#### （二）社会主义发展道路具有多样性

**原因**：

1. 各国生产力发展状况不同（根本原因）。
2. 历史文化差异。
3. 时代的不同。

#### （三）社会主义在曲折中发展

**原因**：

1. 社会主义作为一个新生事物，成长不会一帆风顺。
2. 社会主义的基本矛盾推动社会发展，是作为一个过程展开的，人们对它的认识也有一个逐渐发展的过程。
3. 经济全球化对于社会主义的发展既有机遇又有挑战。
