## 概念

咳咳，这只捣乱的吃货猫猫已经被扔出去了。我们这里说的串不是上面那些给小玄馋成翘嘴儿的烧烤什么的，在数据结构中，串指的是字符串，就是由$0$个到多个字符组成的有限序列。通常记为：

$$
S = 'a_1a_2\cdots a_n' (n \ge 0)
$$

其中，$S$是串名，单引号引起来的字符序列是串的值。$n$是串的长度，当$n =0$时，称串为空串。（由空格组成的串不是空串）

下面是一些相关的基础概念：

- 子串：串中任意多个连续字符组成的子序列称为该串的子串。

- 主串：包含该子串的串

- 字符在串中的位置：该字符在串中的序号

- 子串在主串中的位置：子串第一个字符在主串中的位置

- 串的相等：两个串长度相等，且对应位置上字符完全相同

## C/C++中的字符串

### C语言中的字符串

纯$C$语言环境中如果你想表示一个字符串，必须使用$char$类型的指针或数组，且必须在末尾多留出一位“\0”结尾。由于$C$语言本身不提供对字符串的赋值，拼接，比较等操作，所以必须借助头文件<$string.h$>来实现。以下是该头文件中的常用函数

| 函数 | 功能 | 示例 |
| :--- | :--- | :--- |
| `strlen(s)` | 求字符串长度（不含 `'\0'`） | `strlen("abc")` → 3 |
| `strcpy(dest, src)` | 字符串拷贝 | `strcpy(a, "hello")` |
| `strncpy(dest, src, n)` | 拷贝最多 n 个字符 | 更安全 |
| `strcat(dest, src)` | 字符串拼接 | `strcat(a, " world")` |
| `strncat(dest, src, n)` | 拼接最多 n 个字符 | |
| `strcmp(s1, s2)` | 字符串比较 | 返回 <0, 0, >0 |
| `strncmp(s1, s2, n)` | 比较前 n 个字符 | |
| `strchr(s, c)` | 查找字符首次出现 | 返回指针 |
| `strrchr(s, c)` | 查找字符最后一次出现 | |
| `strstr(s1, s2)` | 查找子串 | 返回指针 |
| `strtok(s, delim)` | 分割字符串 | 按分隔符切分 |
| `memset(ptr, val, n)` | 内存块填充 | 常用于初始化 |
| `memcpy(dest, src, n)` | 内存块拷贝 | 可拷贝任意类型 |
| `memmove(dest, src, n)` | 内存块移动（处理重叠） | |
| `memcmp(p1, p2, n)` | 内存块比较 | |

> 这些函数都操作 `char*`，需要你自己保证目标缓冲区足够大，否则会溢出（这是 C 字符串最大的安全隐患）。

### C++中的字符串

在$C++$中，字符串定义在<$string$>头文件里，下面是这个头文件的常见用法：

```cpp
#include <string>
using namespace std;

// 初始化和赋值
string s1;                  // 空字符串
string s2 = "hello";        // 用 C 字符串初始化
string s3("world");         // 同上
string s4(s2);              // 拷贝构造
string s5(5, 'a');          // "aaaaa"
string s6 = s2 + " " + s3;  // 拼接

// 容量操作
s.size();        // 返回字符个数，O(1)
s.length();      // 同 size()
s.empty();       // 是否为空，O(1)
s.capacity();    // 当前分配的内存能容纳多少字符
s.reserve(n);    // 预分配至少 n 个字符的空间，避免多次扩容
s.resize(n);     // 改变大小为 n，多出的字符默认 '\0'，少则截断
s.clear();       // 清空字符串，size 变为 0

// 访问元素
s[i];            // 下标访问，不检查越界，O(1)
s.at(i);         // 下标访问，越界抛 out_of_range 异常，O(1)
s.front();       // 第一个字符，O(1)
s.back();        // 最后一个字符，O(1)
s.data();        // 返回 C 风格字符串指针（C++11 起保证以 '\0' 结尾）
s.c_str();       // 返回 const char*，常用于C函数接口

// 修改操作
s += "abc";              // 追加字符串
s.append("def");         // 追加
s.push_back('x');        // 追加一个字符，O(1) 均摊
s.pop_back();            // 删除最后一个字符（C++11）
s.insert(pos, "str");    // 在 pos 处插入字符串，O(n)
s.erase(pos, len);       // 从 pos 开始删除 len 个字符，O(n)
s.replace(pos, len, "new"); // 替换子串
s.swap(s2);              // 交换两个字符串

// 查找子串和比较
s.find("abc");           // 查找子串首次出现位置，找不到返回 string::npos
s.rfind("abc");          // 从后往前找
s.find('x');             // 查找字符
s.substr(pos, len);      // 返回从 pos 开始长度为 len 的子串，O(len)
s.compare(s2);           // 比较，类似 strcmp，返回小于0, 0, 大于0

// 迭代器
s.begin();               // 指向首字符
s.end();                 // 指向尾后位置
s.rbegin();              // 反向迭代器
s.rend();
// 可用范围 for 遍历
for (char c : s) cout << c;

// 与C字符串和整数的类型转换
const char* p = s.c_str();          // string -> C 字符串
string s = "123";
int n = stoi(s);                    // string -> int
double d = stod(s);                 // string -> double
string s2 = to_string(456);         // 数值 -> string
```

# 串的模式匹配

所谓模式匹配，就是在主串中查找与模式串（待搜索的字符串）完全相同的子串，并返回其首次出现的位置。

首先介绍一种最简单的做法——暴力匹配

## 大力出奇迹的暴力搜索

```cpp
int ViolenceSearch(const string& text, const string& pattern) 
{
	int n = text.size();	// 主串长度
	int m = pattern.size();	// 模式串长度

	for(int i = 0; i <= n - m; ++i) 
	{
		int j = 0;
		while(j < m && text[i + j] == pattern[j]) 
		{
			++j;
		}
		if(j == m) 
		{
			return i; // 找到匹配，返回起始位置
		}
	}
	return -1; // 未找到匹配，返回-1
}
```

不用我说，大家也能看出来这个算法用了双层循环，时间复杂度达到了$O(mn)$。也就是说，模式串或主串但凡长一点，那算法的执行时间将会特别长。而且能看出来，如果一次匹配失败了，那么模式串就会右滑一位，然后重新比较。这个过程中，指针$i$发生了回溯。

那么怎么解诀时间的问题呢？我们可以这样想：

**分析模式串本身的结构，如果已经匹配成功的序列中有后缀正好是模式串的前缀，那么就可以将模式串右滑到与这些字符对齐的位置，而无需回溯指针$i$。**而这，就是KMP模式匹配的核心思想。

## KMP模式匹配算法

### 概念

- 前缀：指除了最后一个字符之外，字符串的所有头部字串，即从第一个字符开始的，不走到最后一个字符的子串。

- 后缀：指除了第一个字符外，字符串的所有尾部子串，即从除了第一个字符之外的所有字符开始，走到最后一个字符的子串。

- 部分匹配值：指字符串中前缀和后缀的最长相等前后缀长度，即一个字符串的所有前缀和后缀之中，能找到的最长的相等的串的长度。

例如模式串'$ababa$'，我们分析他的每一个子串：

- '$a$'的前缀和后缀都是空串，最长相等前后缀长度是0。

- '$ab$'的前缀为$\{a\}$，后缀为$\{b\}$。$\{a\} \cap \{b\} = \varnothing$，最长相等前后缀长度是0。

- '$aba$'的前缀为$\{a, ab\}$，后缀为$\{a, ba\}$，二者取交集结果为$\{a\}$，最长相等前后缀长度是1。
